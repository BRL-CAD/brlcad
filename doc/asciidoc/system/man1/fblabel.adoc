== NAME
fblabel - display a text string on a framebuffer

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*fblabel* [*-a*] [*-c*] [*-d*] [*-F* _device_] [*-f* _name_] [*-C* _r/g/b_] [*-s* _pixels_]
        [*-w* _pixels_] [*-n* _pixels_] _x-position_ _y-position_ _text_
// END GENERATED BU_ARG SYNOPSIS


[[description]]
== DESCRIPTION

*fblabel* writes a text string onto the image of the currently selected
framebuffer. By default the text is anti-aliased (Gaussian filtered)
against the existing image, so the label blends with whatever is already
displayed. The lower-left corner of the text begins at the given
_x_position_ and _y_position_ (in pixels); use *fbpoint*(1) to
interactively locate a position.

The environment variable FB_FILE specifies the current framebuffer; see
*brlcad*(1). The framebuffer may instead be named with the *-F* flag.

The text is drawn using a Berkeley *vfont*-format font. The default font
is _nonie.r.12_. Fonts are located in BRL-CAD's data directory under
_vfont/_, falling back to _/usr/lib/vfont_. The default text color is
white (255/255/255).


[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*[_all_], *--help*[=_all_]::
  Print help and exit; use --help=all for compatibility options.

*-a*, *--no-antialias*::
  Render text without antialiasing.

*-c*, *--clear*::
  Clear the framebuffer before drawing.

*-d*, *--debug*::
  Print character layout diagnostics.

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer device.

*-f* _name_, *--font*=_name_::
  Select a vfont font.

*-C* _r/g/b_, *--color*=_r/g/b_::
  Set the text color (default 255/255/255).

*-r* _value_, *--red*=_value_::
  Override the red text-color channel.

*-g* _value_, *--green*=_value_::
  Override the green text-color channel.

*-b* _value_, *--blue*=_value_::
  Override the blue text-color channel.

*-s* _pixels_, *--size*=_pixels_::
  Set both framebuffer dimensions.

*-w* _pixels_, *--width*=_pixels_::
  Set the framebuffer width.

*-n* _pixels_, *--height*=_pixels_::
  Set the framebuffer height.

// END GENERATED BU_ARG OPTIONS

The uppercase *-S*, *-W*, and *-N* spellings remain accepted as hidden
compatibility aliases.  The *-r*, *-g*, and *-b* channel options are also
retained for compatibility and are listed by *--help=all*.  When combined
with *--color*, color settings take effect in command-line order.


[[examples]]
== EXAMPLES

.Caption a rendered image
====
[source,console]
----
$ pix-fb moss.pix
$ fblabel -C 255/255/0 10 10 "moss scene"
----
Display a rendered image with *pix-fb*(1), then stamp a yellow caption in
the lower-left corner, anti-aliased over the existing pixels.
====

.Position a label interactively with fbpoint
====
[source,console]
----
$ fblabel -f oldenglish.14 `fbpoint` "Title"
----
Use *fbpoint*(1) to click a location on the framebuffer; its emitted
coordinates become the _x_position_ and _y_position_ for the label, drawn
here in the oldenglish.14 font.
====
