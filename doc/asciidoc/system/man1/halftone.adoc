== NAME

halftone - convert a black and white image to a halftoned black and white image

[[description]]
== DESCRIPTION

*halftone* reads a black and white image in *bw*(5) format from the
named file (or from standard input if no file is given) and writes a
halftoned *bw*(5) image to standard output.  Halftoning reduces the 256
possible input intensities to two output levels by default (black and white)
while using dithering to preserve as much apparent shading and detail as
possible.  Several dithering algorithms are available via the *-M* option,
ranging from Floyd-Steinberg error diffusion to ordered halftone screens.

The output is itself a *bw*(5) file whose pixels take a limited set of
values; each output level is scaled to the range 0 to 255 (as 255 /
(_levels_ - 1) * _value_) so the result displays correctly with tools
such as *bw-pix*(1).  The dithering algorithms are drawn largely from
_Digital Halftoning_ by Robert Ulichney.

The *-T* option fits a cubic spline through one or more increasing X Y
control-point pairs, with every coordinate in the range 0 through 255.  That
spline maps input intensities before dithering.  Without *-T*, the mapping is
the straight line from 0 0 through 255 255.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-a*, *--autosize*::
  Infer dimensions from a named input file.

*-s* _pixels_, *--size*=_pixels_::
  Set both image dimensions.

*-w* _pixels_, *--width*=_pixels_::
  Set image width (default: 512).

*-n* _scanlines_, *--height*=_scanlines_::
  Set image height (default: 512).

*-B* _beta_, *--sharpen*=_beta_::
  Set the finite Laplacian sharpening coefficient (default: 0).

*-I* _count_, *--levels*=_count_::
  Set output intensity levels from 2 through 256.

*-M* _number_, *--method*=_number_::
  Select 0 Floyd-Steinberg, 1 45-degree classic, 2 threshold, or 3 0-degree dispersed.

*-R*, *--randomize*::
  Add random noise to dither thresholds.

*-S*, *--serpentine*::
  Reverse alternate Floyd-Steinberg scanlines (ignored by other methods).

*-T* _x y ..._, *--tone-map*=_x y ..._::
  Fit a cubic tone map through increasing 0..255 X Y control points.

*-D* _level_, *--debug*=_level_::
  Set diagnostic level (9 enables all messages).

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Render a model and halftone the result for a 1-bit display
====
[source,console]
----
$ rt -s 512 -o image.pix model.g component.r
$ pix-bw image.pix > image.bw
$ halftone -M 0 -S image.bw > image.ht.bw
----
Ray traces a region to a 512x512 color image, converts it to *bw*(5)
grayscale, then applies Floyd-Steinberg error diffusion with a
serpentine scan to produce a dithered black-and-white image suitable
for a 1-bit device.
====

.Coarse newsprint-style halftone with four gray levels
====
[source,console]
----
$ halftone -w 1024 -n 768 -M 1 -I 4 photo.bw > photo.ht.bw
----
Treats the input as a 1024x768 image and applies the 45-degree
classical clustered-dot screen quantized to four intensity levels,
mimicking a coarse printed halftone.
====
