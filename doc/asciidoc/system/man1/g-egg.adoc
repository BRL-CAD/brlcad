== NAME

g-egg - convert BRL-CAD geometry to a Panda3D EGG file

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*g-egg* [*-v*] [*-8*] [*-a* _distance_] [*-r* _fraction_] [*-n* _degrees_] [*-D* _distance_]
      [*-x* _mask_] [*-X* _mask_] [*-o* _output.egg_] _database.g_ _object_ ...
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*g-egg* converts the specified geometry _object(s)_ from a BRL-CAD
_database.g_ to a Panda3D EGG file. Each object is tessellated into a
triangulated NMG via the boolean evaluator and written as an EGG
`<Group>` containing a vertex pool and the resulting polygons. The
output uses a Z-Up coordinate system.

If no output file is given with *-o*, the EGG data is written to
standard output. A count of the triangles produced is printed to
standard error on completion.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-v*, *--verbose*::
  Report detailed conversion settings.

*-8*, *--marching-cubes*::
  Use marching cubes instead of NMG Boolean evaluation.

*-a* _distance_, *--absolute-tolerance*=_distance_::
  Set nonnegative maximum chord deviation in millimeters and clear relative tolerance.

*-r* _fraction_, *--relative-tolerance*=_fraction_::
  Set nonnegative tolerance as a fraction of the bounding box (default 0.01).

*-n* _degrees_, *--normal-tolerance*=_degrees_::
  Set nonnegative surface-normal tolerance in degrees and clear relative tolerance.

*-D* _distance_, *--distance-tolerance*=_distance_::
  Set nonnegative vertex-coincidence distance in millimeters (default 0.0005).

*-x* _mask_, *--rt-debug*=_mask_::
  Set librt hexadecimal debug flags.

*-X* _mask_, *--nmg-debug*=_mask_::
  Set libnmg hexadecimal debug flags.

*-o* _output.egg_, *--output*=_output.egg_::
  Write EGG data to this file instead of standard output.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert objects from a database to an EGG file
====
[source,console]
----
$ g-egg -r 0.005 -o havoc.egg havoc.g body wings
----
Tessellates the *body* and *wings* regions from *havoc.g* using a tighter
relative tolerance of 0.005 and writes the combined Panda3D EGG model to
*havoc.egg*, ready to be loaded into a Panda3D scene.
====

.Generate geometry on demand and pipe it onward
====
[source,console]
----
$ g-egg -a 0.5 moss.g all.g > moss.egg
----
Facetizes the *all.g* assembly from the *moss.g* sample database with a
0.5 mm absolute tolerance and redirects the EGG output (which would
otherwise go to standard output) into *moss.egg*.
====
