== NAME
png-bw - convert a PNG (Portable Network Graphics) file to a BW (black and white) file

== SYNOPSIS

[verse]
*png-bw* [*-v*] [*-e* _scheme_] [*-R*[_weight_]] [*-G*[_weight_]] [*-B*[_weight_]] [_input_]
// END GENERATED BU_ARG SYNOPSIS


[[description]]
== DESCRIPTION

*png-bw* reads a _PNG_ image from the named file (or from standard input
if no file is given) and writes a single-channel *bw*(5) image to standard
output. If the input is already grayscale the data is passed through
directly; if the input is a color image it is reduced to black and white.

By default all three color planes are weighted equally. The
*--encoding=ntsc* setting applies the standard NTSC luminance weights based
on the NTSC primaries and the D6500 white. The *--encoding=crt* setting
applies weights for typical CRT phosphor chromaticities and the D6500 white.

Individual color planes can be selected with the *-R*, *-G*, and *-B* flags.
If a flag is immediately followed by a value, that value is used as the
weight applied to that plane. A selected plane with no explicit weight is
implicitly given a weight of 1.0 divided by the number of selected planes.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-v*, *--verbose*::
  Report PNG image and metadata details.

*-e* _scheme_, *--encoding*=_scheme_::
  Select a luminance weighting scheme. Accepted values: *ntsc*, *crt*.

*-R*[_weight_], *--red-weight*[=_weight_]::
  Select red, optionally with an attached weight.

*-G*[_weight_], *--green-weight*[=_weight_]::
  Select green, optionally with an attached weight.

*-B*[_weight_], *--blue-weight*[=_weight_]::
  Select blue, optionally with an attached weight.

// END GENERATED BU_ARG OPTIONS

*--verbose* reports the color type, bit depth, image dimensions, gamma,
background color, interlacing, and available text or timestamp metadata to
standard error.  The `ntsc` encoding uses red, green, and blue weights of
0.30, 0.59, and 0.11; `crt` uses 0.26, 0.66, and 0.08.  A channel option with
no attached weight shares equal weight with the other selected channels.

[[examples]]
== EXAMPLES

.Convert a color rendering to grayscale and view it
====
[source,console]
----
$ png-bw --encoding=ntsc render.png > render.bw
$ bw-pix render.bw | pix-fb -w 512 -n 512
----
Reduces a color _PNG_ to a perceptually weighted grayscale *bw*(5) image
using NTSC luminance weights, then converts it back to *pix*(5) and displays
it on a framebuffer with *pix-fb*(1).
====

.Blend selected color planes with custom weights
====
[source,console]
----
$ png-bw -R0.30 -G0.59 -B0.11 file.png > file.bw
----
Combines the red, green, and blue planes with the given weights; this
produces the same result as *--encoding=ntsc*. Selecting planes without
weights, as in *png-bw -R -B file.png*, blends those planes equally.
====
