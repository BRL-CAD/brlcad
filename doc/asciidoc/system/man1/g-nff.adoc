== NAME

g-nff - BRL-CAD to Neutral File Format (NFF) translator

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*g-nff* [*-v*] [*-a* _distance_] [*-r* _fraction_] [*-n* _degrees_] [*-D* _distance_]
      [*-e* _warnings.log_] [*-x* _mask_] [*-X* _mask_] (*-o* _output.nff_) _database.g_
      _object_ ...
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*g-nff* converts the specified geometry _object(s)_ from a BRL-CAD _database.g_
file to the Neutral File Format (NFF). Each region is evaluated with the NMG
boolean routines, triangulated, and written as a set of NFF polygons tagged
with the region's color. *g-nff* also computes a bounding box for the geometry
and emits a default 45-degree view, light, and 512x512 resolution into the
output so the result can be rendered directly.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-v*, *--verbose*::
  Report detailed conversion progress.

*-a* _distance_, *--absolute-tolerance*=_distance_::
  Set nonnegative maximum chord deviation in millimeters and clear relative tolerance.

*-r* _fraction_, *--relative-tolerance*=_fraction_::
  Set nonnegative tolerance as a fraction of the bounding box (default 0.01).

*-n* _degrees_, *--normal-tolerance*=_degrees_::
  Set nonnegative surface-normal tolerance in degrees and clear relative tolerance.

*-D* _distance_, *--distance-tolerance*=_distance_::
  Set nonnegative vertex-coincidence distance in millimeters (default 0.0005).

*-e* _warnings.log_, *--error-file*=_warnings.log_::
  Write Boolean-elimination warnings to this file instead of standard error.

*-x* _mask_, *--rt-debug*=_mask_::
  Set librt hexadecimal debug flags.

*-X* _mask_, *--nmg-debug*=_mask_::
  Set libnmg hexadecimal debug flags.

*-o* _output.nff_, *--output*=_output.nff_::
  Write the converted geometry and generated view to this NFF file.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert selected regions to a renderable NFF file
====
[source,console]
----
$ g-nff -a 0.5 -o engine.nff engine.g block piston
----
Tessellates the *block* and *piston* regions from *engine.g* using a 0.5 mm
absolute tolerance and writes the triangulated geometry, together with a
default view and light, to *engine.nff*, ready to be passed to an NFF-capable
renderer.
====
