== NAME

iges-g - convert an IGES file to a BRL-CAD database

== SYNOPSIS

[source]
----
iges-g [--exact|--strict] [--repair _none|safe_] [--report _file.json_] [-3] [-d] [-n] [-t] [-m|-p] [-N _solid_name_] [-x _rt_debug_flag_] [-X _nmg_debug_flag_] -o _database.g_ _file.iges_
----


[[description]]
== DESCRIPTION

*iges-g* reads an IGES (Initial Graphics Exchange Specification) file and
writes the converted geometry to a BRL-CAD _database.g_ file. The input is
expected to conform to IGES version 5.3 or an earlier version.

With none of the *-3*, *-d*, *-n*, or *-t* options, the default action is to
convert IGES solid model entities to their BRL-CAD equivalents. Type 186
manifold topology is constructed directly in OpenNURBS. Type 144 trimmed
surfaces are constructed as independent OpenNURBS faces and conservatively
stitched into shared manifold topology when their boundary curves agree within
the file tolerance. Most CSG conversions are exact; solids
of revolution are approximated by a series of BRL-CAD cones and solids of
linear extrusion are approximated by polysolids. BREP objects are written as
native BRL-CAD BRep objects by default; *-m* and *-p* select polygonal
fallbacks.

The *-3*/*-d*, *-n*, and *-t* options are mutually exclusive and select
alternate conversion modes (drawings, B-spline surfaces, or trimmed surfaces,
respectively). The *-o* output option is required. When the chosen mode cannot
represent something present in the file, *iges-g* prints suggestions for the
options that would convert the remaining entities. To export geometry in the
other direction, see *g-iges*(1).

[[options]]
== OPTIONS

*-3*::
  Preserve drawing model-space planes instead of projecting them to XY.

*-d*::
  Convert IGES drawings to native BRL-CAD sketch and annotation objects,
  preserving text, leaders, grouping, and style metadata when possible.

*-n*::
  Combine all rational B-spline surfaces in the IGES file into a single
  BRL-CAD spline solid.

*-t*::
  Request the legacy trimmed-surface conversion mode. The default mode imports
  supported type 144 surfaces directly as OpenNURBS faces and assembles shared
  topology without using NMG.

*-p*::
  Write BREP objects as polygonal NMG solids instead of native BRep objects.

*-m*::
  Write BREP objects as triangulated BOT solids instead of native BRep objects.

*--exact*::
  Disallow source-data repairs during direct geometry or annotation import.

*--strict*::
  Reject repaired or partial direct imports.

*--repair* _none|safe_::
  Select no repairs or bounded structural repairs. The default is _safe_.

*--report* _file.json_::
  Write structured parser and import diagnostics to a JSON file.

*-o* _database.g_::
  Specify the output BRL-CAD database file. This option is required.

*-N* _solid_name_::
  Name the single solid created by the *-n* or *-t* option. If not given, the
  default name "all" (or a unique variant) is used. Ignored for all other
  modes.

*-x* _rt_debug_flag_::
  Set the librt debug flag, given as a hexadecimal value. See _raytrace.h_ for
  the bit definitions.

*-X* _nmg_debug_flag_::
  Set the NMG routine debug flag, given as a hexadecimal value. See _nmg.h_
  for the bit definitions.

[[examples]]
== EXAMPLES

.Convert IGES solid geometry and inspect the result
====
[source,bash]
----
iges-g -o widget.g widget.iges
mged widget.g 'tops'
----
Convert the CSG and BREP entities of _widget.iges_ into
_widget.g_, then list the resulting top-level objects with *mged*(1) to verify
the conversion.
====

.Assemble trimmed surfaces into a BRep
====
[source,bash]
----
iges-g --strict --report boat-import.json -o boat.g boat.iges
----
Build the supported trimmed surfaces in _boat.iges_ directly as OpenNURBS
faces, stitch coincident naked edges conservatively, and write diagnostics to
_boat-import.json_.
====
