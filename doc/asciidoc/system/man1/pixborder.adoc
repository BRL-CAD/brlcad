== NAME
pixborder - add a 1-pixel-wide border to regions of a specified color

== SYNOPSIS

          [*-n* _pixels_] [*-x* _column_] [*-X* _column_] [*-y* _row_] [*-Y* _row_] [_input_]

[[description]]
== DESCRIPTION

*pixborder* reads a stream of *pix*(5) data, finds maximal contiguous regions of
a specified interior color, and writes out *pix*(5) data with every pixel on the
boundary of such a region replaced by a border color. (This outlines colored
regions; it does not draw a frame around the whole image.) With no input file
given, data is read from standard input; output always goes to standard output.

Whether a pixel is on a boundary depends on the interior and exterior colors.
The default interior color is 255 255 255 (white) and the default exterior color
is 1 1 1. If both or neither color is specified, a pixel is on the boundary when
it has the interior color and at least one of its four neighbors (left, right,
above, below) has the exterior color. If only one color is specified, a pixel is
on the boundary when it matches (or, for an exterior-only specification, does not
match) that color and at least one neighbor differs accordingly.

Colors may be given in RGB (channels in {0..255}) or HSV (with _H_ in [0, 360]
and _S_, _V_ in [0, 1]); a hue of 360 is equivalent to 0. A symmetric
per-channel tolerance (*-t* or *-T*) lets nearby colors be treated as the
nominal interior or exterior color.


[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-a*, *--autosize*::
  Infer dimensions from a named input file.

*-b* _red green blue_, *--border-rgb*=_red green blue_::
  Set the RGB border color using channels from 0 to 255 (default: 1 1 1).

*-B* _hue saturation value_, *--border-hsv*=_hue saturation value_::
  Set the HSV border color (H 0..360; S and V 0..1).

*-e* _red green blue_, *--exterior-rgb*=_red green blue_::
  Set the RGB exterior color using channels from 0 to 255 (default: 1 1 1).

*-E* _hue saturation value_, *--exterior-hsv*=_hue saturation value_::
  Set the HSV exterior color (H 0..360; S and V 0..1).

*-i* _red green blue_, *--interior-rgb*=_red green blue_::
  Set the RGB interior color using channels from 0 to 255 (default: 255 255 255).

*-I* _hue saturation value_, *--interior-hsv*=_hue saturation value_::
  Set the HSV interior color (H 0..360; S and V 0..1).

*-t* _red green blue_, *--rgb-tolerance*=_red green blue_::
  Set per-channel RGB matching tolerance from 0 to 255 (default: 0 0 0).

*-T* _hue saturation value_, *--hsv-tolerance*=_hue saturation value_::
  Set HSV matching tolerance (H 0..360; S and V 0..1).

*-s* _pixels_, *--size*=_pixels_::
  Set both image dimensions.

*-w* _pixels_, *--width*=_pixels_::
  Set image width (default: 512).

*-n* _pixels_, *--height*=_pixels_::
  Set image height (default: 512).

*-x* _column_, *--left*=_column_::
  Set the leftmost processed column (default: 0).

*-X* _column_, *--right*=_column_::
  Set the rightmost processed column (default: image edge).

*-y* _row_, *--bottom*=_row_::
  Set the lowest processed row (default: 0).

*-Y* _row_, *--top*=_row_::
  Set the highest processed row (default: image edge).

// END GENERATED BU_ARG OPTIONS


[[examples]]
== EXAMPLES

.Outline red regions in yellow
====
[source,console]
----
$ pixborder -i '255 0 0' -b '255 255 0' -t '40 40 40' scene.pix > outlined.pix
----
Outlines every red region (red 255 0 0, with a tolerance of 40 per channel to
catch anti-aliased edges) by recoloring its boundary pixels yellow.
====

.Draw a multi-pixel-wide border with a pipeline
====
[source,console]
----
$ pixborder -i '255 0 0' -b '0 0 0' scene.pix | \
    pixborder -i '255 0 0' -b '0 0 0' > thick.pix
----
*pixborder* only thickens by one pixel per pass, so chaining several invocations
in a pipeline widens the border. To build a border of constant-thickness bands of
different colors, produce all segments of an outer layer before any of the next
inner layer.
====
