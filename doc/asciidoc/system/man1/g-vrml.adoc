== NAME

g-vrml - convert a BRL-CAD geometry database to a VRML 2.0 file

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*g-vrml* [*-b* | *-e*] [*-v*]... [*-d* _millimeters_] [*-a* _millimeters_] [*-r* _fraction_]
       [*-n* _degrees_] [*-u* _units_] [*-o* _output.wrl_] [*-x* _mask_] [*-X* _mask_] _database.g_
       _object_ ...
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*g-vrml* converts the named objects from a BRL-CAD geometry database
(_database.g_) into a faceted Virtual Reality Modeling Language (VRML)
version 2.0 file. By default each region is tessellated and its Boolean
operations are evaluated through the NMG routines, producing a triangulated
*IndexedFaceSet* per region. Region colors and shaders (plastic, glass,
texture) are translated into VRML material and texture nodes, and regions
using the *light* shader are emitted as VRML light sources.

The result is written to the file named with *-o*, or to standard output if
*-o* is not given. Output units default to millimeters; see *-u* to select a
different unit. The conversion is the inverse direction of importers such as
*vrml-g* would be, and complements other geometry exporters such as
*g-stl*(1) and *g-obj*(1).

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-b*, *--bot-only*::
  Write BoT primitives directly and skip non-BoT geometry.

*-e*, *--evaluate-all*::
  Evaluate Boolean geometry for both CSG and BoT primitives.

*-v*, *--verbose*::
  Increase conversion progress reporting. May be repeated.

*-d* _millimeters_, *--distance-tolerance*=_millimeters_::
  Set nonnegative vertex-coincidence distance in millimeters (default 0.005).

*-a* _millimeters_, *--absolute-tolerance*=_millimeters_::
  Set nonnegative maximum chord error in millimeters and clear relative tolerance.

*-r* _fraction_, *--relative-tolerance*=_fraction_::
  Set nonnegative tolerance as a fraction of bounding-box size (default 0.01).

*-n* _degrees_, *--normal-tolerance*=_degrees_::
  Set nonnegative surface-normal tolerance in degrees and clear relative tolerance.

*-u* _units_, *--units*=_units_::
  Write coordinates in these recognized BRL-CAD units (default mm).

*-o* _output.wrl_, *--output*=_output.wrl_::
  Write VRML output to this file instead of standard output.

*-x* _mask_, *--rt-debug*=_mask_::
  Set librt hexadecimal debug flags.

*-X* _mask_, *--nmg-debug*=_mask_::
  Set libnmg hexadecimal debug flags.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert specific tops objects to a VRML file
====
[source,console]
----
$ g-vrml -o havoc.wrl -u m havoc.g havoc
----
Tessellates and Boolean-evaluates the *havoc* object from havoc.g and writes
a VRML 2.0 model in meters to havoc.wrl, ready to load in a web or desktop
VRML viewer.
====

.Export only the triangle meshes from a model
====
[source,console]
----
$ g-vrml -b -o meshes.wrl model.g body wheels
----
Dumps the *BOT* meshes contained under the *body* and *wheels* objects
directly, skipping CSG primitives and the comparatively slow Boolean
evaluation. This is useful when a model is already mostly faceted and you
want a fast export.
====
