== NAME
bolt - create a BRL-CAD geometry database containing bolts

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS

*bolt* [*-o* _1|2|3|4_] [*-f* _database.g_] [*-n* _count_] [*--head-diameter* _millimeters_]
     [*--head-height* _millimeters_] [*--washer-diameter* _millimeters_]
     [*--washer-height* _millimeters_] [*--stem-diameter* _millimeters_]
     [*--stem-height* _millimeters_]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*bolt* creates a BRL-CAD geometry database (.g) containing one of four
kinds of bolt: a bare bolt head, a head with washer, a head with washer
and stem, or a head with stem. The bolt head is modeled as a hexagonal
prism (two *arb8* solids); the washer and stem are modeled as right
circular cylinders (*rcc* solids). Up to 256 identical bolts may be
created per run, each as its own region and group. All dimensions are
in millimeters.

If invoked with no arguments, *bolt* runs interactively and prompts for
the bolt type, output file name, count, and each required dimension.
Otherwise every parameter is taken from the command line. Historical
attached forms such as *-hd30* remain accepted for compatibility.

[[options]]
== OPTIONS

*-h*, *-?*, *--help*::
  Print help and exit.

*-o*, *--type* _1|2|3|4_::
  Type of bolt: 1 = head only; 2 = head and washer; 3 = head, washer,
  and stem; 4 = head and stem.

*-f*, *--output* _name.g_::
  Name of the output .g database file (default bolt.g in interactive
  mode).

*-n*, *--count* _count_::
  Number of bolts to create, from 1 to 256.

*--head-diameter* _millimeters_::
  Diameter of the bolt head, measured flat edge to flat edge. The legacy
  attached form *-hd*__millimeters__ is also accepted.

*--head-height* _millimeters_::
  Height of the bolt head. The legacy attached form *-hh*__millimeters__ is
  also accepted.

*--washer-diameter* _millimeters_::
  Diameter of the washer (types 2 and 3). The legacy attached form
  *-wd*__millimeters__ is also accepted.

*--washer-height* _millimeters_::
  Height of the washer (types 2 and 3). The legacy attached form
  *-wh*__millimeters__ is also accepted.

*--stem-diameter* _millimeters_::
  Diameter of the bolt stem (types 3 and 4). The legacy attached form
  *-sd*__millimeters__ is also accepted.

*--stem-height* _millimeters_::
  Height of the bolt stem (types 3 and 4). The legacy attached form
  *-sh*__millimeters__ is also accepted.

[[examples]]
== EXAMPLES

.Generate a hex-head bolt with washer and stem, then raytrace it
====
[source,console]
----
$ bolt --type 3 --output bolt.g --count 1 --head-diameter 30 \
    --head-height 10 --washer-diameter 40 --washer-height 3 \
    --stem-diameter 12 --stem-height 80
$ rt -o bolt.png bolt.g bolta
----
This creates a single complete bolt (option 3: head, washer, and stem)
in bolt.g with a 30 mm hex head 10 mm tall, a 40 mm washer 3 mm thick,
and a 12 mm stem 80 mm long, then renders the resulting group "bolta"
to an image with *rt*(1).
====
