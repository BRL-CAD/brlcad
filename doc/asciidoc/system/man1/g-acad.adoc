== NAME
g-acad - BRL-CAD to Lockheed Martin ACAD facet file converter

== SYNOPSIS

[verse]
*g-acad* [*-v*]... [*-i*] [*-a* _distance_] [*-r* _fraction_] [*-n* _radians_] [*-D* _distance_]
       [*-P* _count_] [*-e* _diagnostics.log_] [*-x* _mask_] [*-X* _mask_] [*-o* _output.acad_]
       _database.g_ _object_ ...
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*g-acad* converts the specified _object(s)_ from a BRL-CAD _database.g_
file to the Lockheed Martin "Advanced Computer-Aided Design" (ACAD)
facet file format (formerly from General Dynamics). Each region is
tessellated into a triangulated mesh using the NMG boolean evaluator
and written as a separate part. Note that this format has nothing to
do with the Autodesk AutoCAD software.

If no output file is specified with *-o*, the result is written to
standard output.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-v*, *--verbose*::
  Increase conversion progress reporting. May be repeated.

*-i*, *--inches*::
  Write vertex coordinates in inches instead of millimeters.

*-a* _distance_, *--absolute-tolerance*=_distance_::
  Set nonnegative maximum chord deviation in millimeters and clear relative tolerance.

*-r* _fraction_, *--relative-tolerance*=_fraction_::
  Set nonnegative tolerance as a fraction of the bounding box (default 0.01).

*-n* _radians_, *--normal-tolerance*=_radians_::
  Set nonnegative surface-normal tolerance in radians and clear relative tolerance.

*-D* _distance_, *--distance-tolerance*=_distance_::
  Set nonnegative vertex-coincidence distance in millimeters.

*-P* _count_, *--processors*=_count_::
  Accept a positive worker count for compatibility; conversion remains serial.

*-e* _diagnostics.log_, *--error-file*=_diagnostics.log_::
  Write diagnostics to this file instead of standard error.

*-x* _mask_, *--rt-debug*=_mask_::
  Set librt hexadecimal debug flags.

*-X* _mask_, *--nmg-debug*=_mask_::
  Set libnmg hexadecimal debug flags.

*-o* _output.acad_, *--output*=_output.acad_::
  Write ACAD facet data to this file instead of standard output.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert a region to an ACAD facet file
====
[source,console]
----
$ g-acad -o hull.acad vehicle.g hull
----
Tessellates the _hull_ region from _vehicle.g_ and writes the result
to _hull.acad_ in millimeters.
====

.Convert with tighter tolerances and inch units
====
[source,console]
----
$ g-acad -i -a 0.5 -n 0.26 -e convert.log -o tank.acad tank.g turret hull tracks
----
Converts three regions to a single ACAD facet file in inches, using a
0.5 mm absolute tessellation tolerance and a 0.26-radian (about
15-degree) normal tolerance for finer faceting, while logging
diagnostics to _convert.log_.
====
