== NAME
pixfade - darken a pix file

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*pixfade* [_OPTION_]... [_input_]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*pixfade* darkens a color *pix*(5) image, either by scaling every pixel by a
fractional amount or by clamping each color channel to a maximum level.

By default *pixfade* operates in scaling mode: the *-f*, *--fraction* option
gives a multiplier from 0 to 1 applied to the red, green, and blue values of
each pixel, and the *-p*, *--percentage* option specifies the same multiplier
as a percentage from 0 to 100. The default is *-f* 0.5 (*-p* 50.0).

The *-m*, *--maximum* option selects truncation mode instead, supplying a
ceiling pixel level (0 - 255). Each channel is replaced by the minimum of the
ceiling and its original value. When *-m* is given, the *-f* and *-p* options
are ignored.

Input is read from _infile.pix_ if given, otherwise from standard input. The
faded image is written to standard output, and additionally to the file named
by *-o*, *--output*. If both an output file and redirected standard output are
present, the same image is written to each.


[[options]]
== OPTIONS

*-f*, *--fraction* _fraction_::
  Scale every channel of each pixel by _fraction_, which must be between 0
  and 1. Default is 0.5.

*-p*, *--percentage* _percentage_::
  Same as *-f* but expressed as a percentage from 0 to 100; _percentage_ is
  divided by 100 to form the multiplier. Default is 50.0.

*-m*, *--maximum* _level_::
  Truncation mode: clamp each channel to the ceiling _level_ (0 - 255). Values
  outside this range are clamped to the nearest bound. Overrides *-f* and *-p*.

*-s*, *--size* _pixels_::
  Set both input width and height to _pixels_.

*-w*, *--width* _pixels_::
  Set the input scanline width. Default is 512 pixels.

*-n*, *--height* _pixels_::
  Set the number of input scanlines. Default is 512 pixels.

*-o*, *--output* _file.pix_::
  Write the faded image to _file.pix_ in addition to redirected standard output.

*-h*, *--help*::
  Print help and exit.


[[examples]]
== EXAMPLES

.Dim an image to a quarter brightness
====
[source,console]
----
$ pixfade -f 0.25 -w 1024 -n 768 scene.pix > dim.pix
----
Reads the 1024x768 image _scene.pix_ and scales every channel to 25% of its
original value, producing a darkened _dim.pix_.
====

.Clamp highlights and view the result
====
[source,console]
----
$ pixfade -m 200 scene.pix | pix-fb -w 512 -n 512
----
Caps each color channel at 200 to tame bright highlights, then pipes the
result straight to a framebuffer with *pix-fb*(1) for inspection.
====
