== NAME
pix-fb - display a pix format RGB image on a framebuffer

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*pix-fb* [*-1*] [*-m* _scanlines_] [*-a*] [*-i*] [*-c*] [*-z*] [*-F* _device_] [*-p* _seconds_]

       [*-X* _pixels_] [*-Y* _scanlines_] [*-S* _pixels_] [*-W* _pixels_] [*-N* _scanlines_]
       [_input_]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*pix-fb* reads a *pix*(5) format RGB image from the named file, or from standard input if no file is given, and displays it on a framebuffer. The framebuffer defaults to the device named by the *FB_FILE* environment variable (see *brlcad*(1)) and can be overridden with *-F*.

A *pix*(5) file stores each pixel as three *unsigned char* bytes (red, green, blue) with the first pixel at the lower-left corner; scanlines run left-to-right, bottom-to-top. By default the image is assumed to be 512x512 pixels, and the framebuffer is opened at the file's dimensions unless an explicit screen size is requested.

To go the other direction (save a framebuffer image to a *pix*(5) file), use *fb-pix*(1).

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-1*, *--one-line*::
  Force one scanline per framebuffer write.

*-m* _scanlines_, *--multiple-lines*=_scanlines_::
  Write blocks containing this many scanlines.

*-a*, *--autosize*::
  Derive dimensions from a named input file.

*-i*, *--invert*::
  Display scanlines from top to bottom.

*-c*, *--clear*::
  Clear the framebuffer before writing.

*-z*, *--zoom*::
  Zoom and center the displayed image.

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer instead of the FB_FILE environment default.

*-p* _seconds_, *--pause*=_seconds_::
  Wait before closing the framebuffer.

*-s* _pixels_, *--input-size*=_pixels_::
  Set both input dimensions.

*-w* _pixels_, *--input-width*=_pixels_::
  Set the input scanline width.

*-n* _scanlines_, *--input-height*=_scanlines_::
  Set the input image height.

*-x* _pixels_, *--input-x-offset*=_pixels_::
  Skip pixels from the left of each input scanline.

*-y* _scanlines_, *--input-y-offset*=_scanlines_::
  Skip scanlines from the bottom of the input.

*-X* _pixels_, *--screen-x-offset*=_pixels_::
  Offset the image horizontally on the framebuffer.

*-Y* _scanlines_, *--screen-y-offset*=_scanlines_::
  Offset the image vertically on the framebuffer.

*-S* _pixels_, *--framebuffer-size*=_pixels_::
  Set both framebuffer dimensions.

*-W* _pixels_, *--framebuffer-width*=_pixels_::
  Set the framebuffer width.

*-N* _scanlines_, *--framebuffer-height*=_scanlines_::
  Set the framebuffer height.

// END GENERATED BU_ARG OPTIONS

The input dimension options disable autosizing when they occur after
*--autosize*.  A later *--autosize* option re-enables it, so option order is
significant.  Autosizing requires a named input file; it is not available for
redirected standard input.

*--one-line* overrides *--multiple-lines* regardless of option order.  Block
writes are used only for non-inverted, non-zoomed, full-width transfers and can
be significantly faster on some framebuffers.

Input offsets are nonnegative and measured from the lower-left corner of the
input.  Framebuffer offsets use the same origin but may be negative.  A zero
framebuffer width or height tracks the corresponding input dimension.  Zooming
uses equal integer factors in both directions to preserve the image aspect
ratio.

[[examples]]
== EXAMPLES

.Render and display a model
====
[source,console]
----
$ rt -o moss.pix -w 1024 -n 1024 moss.g all.g
$ pix-fb -F /dev/X -a moss.pix
----
Ray traces the _all.g_ object from the _moss.g_ database into a 1024x1024 *pix*(5) image, then displays it on an X11 framebuffer. The *-a* flag autosizes from the file so the explicit dimensions need not be repeated.
====

.Pause so the result stays visible
====
[source,console]
----
$ pix-fb -w 512 -n 512 -p 5 render.pix
----
Displays a 512x512 image and keeps the framebuffer open for 5 seconds before closing, useful in scripts or pop-up framebuffers that would otherwise vanish immediately.
====
