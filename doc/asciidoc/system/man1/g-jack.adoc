== NAME

g-jack - convert a BRL-CAD model to Jack Psurf (.pss) and figure (.fig) files

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*g-jack* [*-v*] [*-d*] [*-f*] [*-u* _distance_] [*-a* _distance_] [*-r* _fraction_] [*-n* _degrees_]
       [*-D* _distance_] [*-p* _text_] [*-P* _count_] [*-x* _mask_] [*-X* _mask_] _database.g_
       _object_ ...
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*g-jack* converts the specified _object(s)_ from a BRL-CAD database _database.g_
into the Jack Psurf format used by the Jack human figure animation and
ergonomic analysis package (originally from the University of Pennsylvania, later
the commercial Tecnomatix Jack from Siemens).

Each region is tessellated through the NMG boolean evaluator and written to its
own polygonal surface file with a *.pss* suffix; the file name is derived from
the region's leaf object name with periods replaced by underscores (Jack's
Peabody language disallows periods). A single Jack figure file with a *.fig*
suffix is also produced, named after _database.g_, that references every
*.pss* segment, records material colors, and connects the segments with joints.
Coordinates are converted from millimeters to centimeters on output.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-v*, *--verbose*::
  Report conversion progress and generated files.

*-d*, *--debug-plots*::
  Write each converted region as a color-matched .plot3 debugging file.

*-f*, *--no-psurf-output*::
  Validate conversion without writing per-region .pss files; still write the .fig file.

*-u* _distance_, *--edgeuse-distance*=_distance_::
  Set nonnegative edgeuse visualization distance (default 2.0).

*-a* _distance_, *--absolute-tolerance*=_distance_::
  Set nonnegative absolute tessellation tolerance in millimeters (default 0.0, disabled).

*-r* _fraction_, *--relative-tolerance*=_fraction_::
  Set nonnegative tessellation tolerance as a fraction of the bounding box (default 0.01).

*-n* _degrees_, *--normal-tolerance*=_degrees_::
  Set nonnegative surface-normal tessellation tolerance in degrees (default 0.0, disabled).

*-D* _distance_, *--distance-tolerance*=_distance_::
  Set nonnegative vertex-coincidence distance in millimeters (default 0.0005).

*-p* _text_, *--prefix*=_text_::
  Prepend text to every generated output filename.

*-P* _count_, *--cpu-count*=_count_::
  Accept a positive CPU count for compatibility; conversion remains serial.

*-x* _mask_, *--rt-debug*=_mask_::
  Set librt hexadecimal debug flags.

*-X* _mask_, *--nmg-debug*=_mask_::
  Set libnmg hexadecimal debug flags.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert selected regions and inspect them
====
[source,console]
----
$ g-jack -p model_ -v -r 0.005 mannequin.g torso left_arm right_arm
----
Tessellates the three named regions from _mannequin.g_ using a tighter relative
tolerance, writing verbose progress to the terminal. The output files are named
with the *model_* prefix (for example *model_torso.pss*) and a *model_mannequin.fig*
figure file is produced that ties the segments together for loading into Jack.
====
