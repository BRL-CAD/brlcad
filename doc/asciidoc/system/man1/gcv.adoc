== NAME
gcv - geometry format converter

== SYNOPSIS

[source]
----
gcv [options] [--input-format _fmt_] [--output-format _fmt_] _input_file_ _output_file_
----

[source]
----
gcv [options] -i _input_file_ -o _output_file_
----


[[description]]
== DESCRIPTION

*gcv* is the unified BRL-CAD geometry converter. It reads a model in one
file format and writes it out in another, selecting the appropriate read
and write filter plugins from *libgcv* based on the file format. Supported
formats include the BRL-CAD database (*.g*), STEP, IGES, STL, and Wavefront
OBJ, among others.

The input and output files may be given as the last two positional
arguments, or named explicitly with *-i* and *-o*. When only one of *-i* or
*-o* is used, the remaining positional argument supplies the other file.

Input recognition combines bounded content inspection and filename evidence.
Output format is inferred from the filename. Either format may instead
be stated as a MIME name or extension with *--input-format* and
*--output-format*, or with a multi-letter
format prefix on the path itself in the form _fmt_:_path_ (e.g.
*step:model.stp*). A single-letter prefix is not recognized as a format, so
that Windows drive letters are not misinterpreted.

*--input-handler* _name_ and *--output-handler* _name_ select an
implementation explicitly. Without these options, dedicated handlers are
preferred over broad-format backends. Equally preferred implementations
require an explicit choice. Installed plugins can register new types at
runtime without adding generated enum values.

Per-filter options may be passed through to the read filter, the write
filter, or both, allowing format-specific behavior to be tuned without
*gcv* needing to know about each option.

[[options]]
== OPTIONS

*--reject-loss* _category_::
  Reject reported losses of _geometry_, _appearance_, _behavior_, _metadata_
  or _all_. Repeat to combine categories. This policy is separate from
  format traits. By default, reported losses are printed and conversion may
  succeed with partial output. For example, *--reject-loss geometry* permits
  reported material loss while refusing known omitted or approximated geometry.
  Coverage depends on the handler's loss reporting. A failure does not imply
  that a handler has rolled back earlier database or file writes.

*--input-trait* _key=value_::
  Require an input format property. Repeat for multiple properties. Missing
  observations may be supplied, but known contradictions are rejected.

*--output-trait* _key=value_::
  Request an output format property supported by the chosen implementation.
  Repeat for multiple properties. Unsupported requests fail before output
  creation. Traits are separate from MIME parameters.
  Native BRL-CAD output accepts *version=4* or *version=5* (the default).
  ASC output accepts *asc.syntax=tcl-commands* (the default) or
  *asc.syntax=legacy-records*. Legacy ASC requires a V4-representable model;
  its syntax choice is independent of the context's native database version.
  PLY output accepts *version=1.0*, *encoding=ascii* or *encoding=binary*,
  and binary *byte-order=little-endian* or *byte-order=big-endian*.
  The writer's legacy *--type* option accepts *asc*, *le*, *be*, or *de*
  (native binary). It can supply choices left unspecified by the MIME request;
  explicit contradictory traits fail before output creation.
  Native OBJ accepts *encoding=ascii*; its existing normal and material
  switches remain conversion options. Native IGES output accepts
  *encoding=ascii*, *version=5.3* and *iges.version-code=11*, including with
  *--faceted* or *--trimmed-surfaces*. IGES input verifies requested revisions
  against Global parameter 23 after parsing; a producer's version string is
  not the IGES standard revision. The obsolete *application/iges* name
  resolves to *model/iges*.

*--list-formats*::
  List runtime MIME types, implementations, operations and capability traits.

*--identify* _file_::
  Inspect the file without converting it. Report candidate MIME types,
  evidence strength, incomplete inspection, and matching implementations.

*-h*, *--help* [_format_]::
  Print help and exit. If a _format_ is named, format-specific help is
  intended to be printed for it.

*-?* [_format_]::
  Same as *-h*.

*-i* _file_, *--input* _file_::
  Read geometry from _file_. The file must exist.

*-o* _file_, *--output* _file_::
  Write geometry to _file_. If _file_ already exists, conversion output is
  appended where the write filter supports it.

*--input-format* _format_::
  Set the input file format explicitly (e.g. *step*, *iges*, *stl*, *obj*),
  overriding extension- and prefix-based detection.

*--output-format* _format_::
  Set the output file format explicitly.

*-I* _opts_, *--input-only-opts* _opts_::
  Pass _opts_ only to the input (read) filter. Consumes arguments until the
  next top-level *gcv* option is encountered.

*-O* _opts_, *--output-only-opts* _opts_::
  Pass _opts_ only to the output (write) filter. Consumes arguments until the
  next top-level *gcv* option is encountered.

*-B* _opts_, *--input-and-output-opts* _opts_::
  Pass _opts_ to both the input and output filters. Consumes arguments until
  the next top-level *gcv* option is encountered.

[[iges_options]]
== IGES FILTER OPTIONS

The IGES reader and writer share their conversion implementation with
*iges-g*(1) and *g-iges*(1). Native CSG, exact B-Reps, and NMG conversion
remain available without changing BRL-CAD's library interfaces.

The reader accepts *--breps-only* (solid and surface geometry, including
native CSG), *--drawings-only*, *--3d-drawings*, *--exact*, *--strict*,
*--repair* _none|safe|best-effort_, *--relative-tolerance* _fraction_, and
*--max-repair-tolerance* _mm_ through *-I*. By default it attempts both model
geometry and drawings; a drawing-only file retains its model-space planes.
The relative boundary repair target defaults to 0.0001 of the local bounding
box diagonal. Strict mode rejects repaired or partial imports.
Safe and best-effort imports also correct clearly inward or inconsistently
oriented isolated closed BRep shells, using the same low-memory signed-volume
check as *iges-g*. Open, nested, overlapping, and uncertain shells are left
unchanged. Orientation corrections are diagnosed and recorded on the objects.

The writer preserves native CSG where representable and uses exact B-Reps
for supported non-CSG primitives. Its *-O* options are *--faceted*,
*--trimmed-surfaces*, *--nurbs*, and *--flatten-brep*, corresponding to the
same export modes in *g-iges*. Tessellation is explicit for regions; existing
polyhedral geometry retains the NMG export path. Output replaces the
destination only after a complete IGES file has been written. A partial
export reports failure even when a readable subset has been written.
The filters honor IGES file units; a non-unit libgcv scale override is
rejected rather than silently ignored.

[[examples]]
== EXAMPLES

.Convert a STEP file into a BRL-CAD database
====
[source,console]
----
$ gcv assembly.stp assembly.g
----
Reads the STEP file _assembly.stp_ and writes a BRL-CAD database
_assembly.g_. Both formats are detected from the file extensions, after
which the result can be inspected with *mged*(1) or rendered with *rt*(1).
====

.Tune a filter while converting OBJ to a .g database
====
[source,console]
----
$ gcv -I --units mm model.obj model.g
----
Converts a Wavefront OBJ mesh to a BRL-CAD database, passing the
*--units mm* option only to the OBJ read filter so that the source
coordinates are interpreted as millimeters.
====

.Override detection with explicit formats
====
[source,console]
----
$ gcv --input-format model/step --output-format model/stl in.dat out.dat
----
Forces the input to be read as STEP and the output written as STL even
though the *.dat* extensions give no hint of the formats involved.
====
