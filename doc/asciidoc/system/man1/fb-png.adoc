== NAME
fb-png - save a framebuffer image as a Portable Network Graphics (PNG) file

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*fb-png* [*-c*] [*-i*] [*-F* _device_] [*-s* _pixels_] [*-w* _pixels_] [*-n* _pixels_]
       [*-g* _value_] [*-#* _1|3_] [_output_]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*fb-png* reads a region of a framebuffer and saves it as a PNG
(Portable Network Graphics) file. If no output file name is given, the
data is written to standard output.

By default the region read is 512x512 pixels in first-quadrant order
(origin at the lower left); use *-s*, *-w*, and *-n* to change the
size. If the open framebuffer is smaller than the requested size, the
region is trimmed to fit. Use *png-fb*(1) to display a PNG file in a
framebuffer.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-c*, *--color-map*::
  Apply a non-linear framebuffer color map; ignored when no map is present or the map is linear.

*-i*, *--inverse*::
  Read bottom-to-top, producing fourth-quadrant output with an upper-left origin.

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer device instead of the FB_FILE environment default.

*-s* _pixels_, *--size*=_pixels_::
  Set both output dimensions (default: 512).

*-w* _pixels_, *--width*=_pixels_::
  Set the output width (default: 512).

*-n* _pixels_, *--height*=_pixels_::
  Set the output height (default: 512).

*-g* _value_, *--gamma*=_value_::
  Set the PNG source gamma (0.6 approximates PC monitors); non-positive values omit the gAMA chunk (default: -1.0).

*-#* _1|3_, *--pixel-bytes*=_1|3_::
  Select grayscale (1) or RGB (3) output (default: 3). Accepted values: *1*, *3*.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Render a model and capture the framebuffer to PNG
====
[source,console]
----
$ rt -s 1024 -F /dev/X moss.g all.g &
$ fb-png -F /dev/X -s 1024 moss.png
----
Ray traces the *moss.g* model into a 1024x1024 X11 framebuffer with
*rt*(1), then grabs that framebuffer and saves it as a PNG image of the
same size. Matching the *-s* size to the framebuffer ensures the whole
image is captured.
====

.Save the lower-left quadrant of the default framebuffer
====
[source,console]
----
$ fb-png -w 256 -n 256 crop.png
----
Reads only a 256x256 region (anchored at the origin) from the
framebuffer named by the *FB_FILE* environment variable and writes it
to crop.png.
====
