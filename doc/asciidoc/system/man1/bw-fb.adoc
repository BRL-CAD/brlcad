== NAME
bw-fb - display a black and white bw image on a framebuffer

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*bw-fb* [*-a*] [*-i*] [*-c*] [*-z*] [*-R*] [*-G*] [*-B*] [*-F* _device_] [*-s* _pixels_]
      [*-w* _pixels_] [*-n* _scanlines_] [*-x* _pixels_] [*-y* _scanlines_] [*-X* _pixels_]
      [*-Y* _scanlines_] [*-S* _pixels_] [*-W* _pixels_] [*-N* _scanlines_] [_input_]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*bw-fb* reads a *bw*(5) format file (from standard input if an input file is not given) and displays the image on the currently selected framebuffer. The environment variable __FB_FILE__ specifies the current framebuffer; see *brlcad*(1). 


[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-a*, *--autosize*::
  Derive dimensions from a named input file.

*-i*, *--invert*::
  Display scanlines from top to bottom.

*-c*, *--clear*::
  Clear the framebuffer before writing.

*-z*, *--zoom*::
  Zoom and center the displayed image.

*-R*, *--red*::
  Write the BW values to the red plane.

*-G*, *--green*::
  Write the BW values to the green plane.

*-B*, *--blue*::
  Write the BW values to the blue plane.

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer instead of the FB_FILE environment default.

*-s* _pixels_, *--input-size*=_pixels_::
  Set both input dimensions.

*-w* _pixels_, *--input-width*=_pixels_::
  Set the input scanline width.

*-n* _scanlines_, *--input-height*=_scanlines_::
  Set the input image height.

*-x* _pixels_, *--input-x-offset*=_pixels_::
  Skip pixels from the left of each input scanline.

*-y* _scanlines_, *--input-y-offset*=_scanlines_::
  Skip scanlines from the bottom of the input.

*-X* _pixels_, *--screen-x-offset*=_pixels_::
  Offset the image horizontally on the framebuffer.

*-Y* _scanlines_, *--screen-y-offset*=_scanlines_::
  Offset the image vertically on the framebuffer.

*-S* _pixels_, *--framebuffer-size*=_pixels_::
  Set both framebuffer dimensions.

*-W* _pixels_, *--framebuffer-width*=_pixels_::
  Set the framebuffer width.

*-N* _scanlines_, *--framebuffer-height*=_scanlines_::
  Set the framebuffer height.

// END GENERATED BU_ARG OPTIONS

If none of the red, green, or blue plane options is selected, *bw-fb*
writes the BW value to all three planes. Input and framebuffer offsets use
a first-quadrant coordinate system with the origin at the lower-left corner.


[[format]]
== FORMAT

A *bw*(5) file contains sequences of pixels. Each pixel is stored as one *unsigned char*. The first pixel in a _bw_ file is the lower left corner of the image. The pixels proceed from left-to-right across each scanline, with scanlines being written from the bottom to the top of the image.


[[examples]]
== EXAMPLES

The following examples demonstrate how to display a _bw_ format file on a framebuffer, including displaying a specific size, autosizing, and displaying only a specific color plane.

.Displaying a 1024x1024 _bw_ file
====
[source,console]
----
$ bw-fb -s 1024 image.bw
----

Displays the 1024x1024 file _image.bw_ on the currently selected framebuffer.
====

.Autosizing and zooming an image
====
[source,console]
----
$ bw-fb -a -z image.bw
----

Attempts to automatically determine the image dimensions from the file size of _image.bw_ and displays it, zooming in and centering it to fill the display area.
====

.Displaying an image only in the red color plane
====
[source,console]
----
$ bw-fb -R image.bw
----

Displays _image.bw_ in the red color plane of the framebuffer, leaving the green and blue planes unaffected.
====
