== NAME
pixdiff - highlight samples which differ between two pix or bw files

== SYNOPSIS

[source]
----
pixdiff _file1.pix_ _file2.pix_ > _out.pix_
pixdiff _file1.bw_ _file2.bw_ > _out.bw_
----


[[description]]
== DESCRIPTION

*pixdiff* compares two raw *pix*(5) or *bw*(5) images byte by byte and
writes a difference image of the same size to standard output. Bytes that
differ by +/-1 are written at intensity 192, while larger differences are
written at full intensity 255. Matching bytes are written at half their
original intensity, providing visual context for locating differences.

Because the comparison does not interpret pixel structure, no format option
is needed and *pixdiff* is independent of image resolution. The two inputs
must be the same size in bytes; otherwise the program reports the mismatch
and exits. Either input file may be given as
*-* to read from standard input. Output must be redirected; *pixdiff*
refuses to write a raw image stream to a terminal.

Upon completion, the count of bytes that matched, that were off by 1, and
that were off by many is reported on standard error.

Also see *bwdiff*(1), which can also operate on *pix*(5) files and can
produce other kinds of difference output.


[[examples]]
== EXAMPLES

.Diff two renderings and view the result
====
[source,bash]
----
pixdiff frame_a.pix frame_b.pix > diff.pix
pix-png -w 512 -n 512 diff.pix > diff.png
----
Compares two 512x512 renderings, writing a highlight image to _diff.pix_,
then converts it to PNG with *pix-png*(1) for easy viewing. Differing
channels glow brightly against a dim grayscale backdrop, making changed
regions easy to spot. The matching/off-by-1/off-by-many byte counts printed
on standard error give a quick quantitative sense of how much changed.
====

.Diff two grayscale images
====
[source,bash]
----
pixdiff depth_a.bw depth_b.bw > depth_diff.bw
----
Writes a grayscale highlight image using the same byte comparison and
statistics as the color example; no format option is needed.
====
