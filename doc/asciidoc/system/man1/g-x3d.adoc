== NAME

g-x3d - convert BRL-CAD geometry to an X3D faceted model

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*g-x3d* [*-v*]... [*-d* _millimeters_] [*-a* _millimeters_] [*-r* _fraction_] [*-n* _degrees_]
      [*-u* _units_] [*-P* _count_] [*-o* _output.x3d_] [*-x* _mask_] [*-X* _mask_] _database.g_
      _object_ ...
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*g-x3d* evaluates the Boolean operations defined by the named regions in a
BRL-CAD database (*.g*) file, tessellates the resulting geometry into NMG
faceted form, and writes it as an X3D (Extensible 3D) scene. Each
non-light-source region is emitted as a separate X3D *Shape* with an
*IndexedFaceSet*, and region colors (or default per-thousand region-id colors)
are written as X3D *Material* nodes. The output is written to the file named
with *-o*, or to standard output otherwise.

*g-x3d* is a modified version of *g-vrml*(1) and shares its shader and material
handling; use it when an XML-based X3D scene is preferred over classic VRML.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-v*, *--verbose*::
  Report region conversion progress on standard error. May be repeated.

*-d* _millimeters_, *--distance-tolerance*=_millimeters_::
  Set nonnegative calculational distance tolerance used to distinguish neighboring vertices, in millimeters (default 0.0005).

*-a* _millimeters_, *--absolute-tolerance*=_millimeters_::
  Set nonnegative maximum chord error between an approximating facet and the true surface, in millimeters, and clear relative tolerance.

*-r* _fraction_, *--relative-tolerance*=_fraction_::
  Set nonnegative tolerance as a fraction of each solid's bounding-box size (default 0.01).

*-n* _degrees_, *--normal-tolerance*=_degrees_::
  Set nonnegative maximum angle between adjacent facet normals, in degrees, and clear relative tolerance.

*-u* _units_, *--units*=_units_::
  Write coordinates in recognized BRL-CAD units such as mm, cm, m, in, or ft (default mm).

*-P* _count_, *--processors*=_count_::
  Use this positive processor count during tessellation (default 1).

*-o* _output.x3d_, *--output*=_output.x3d_::
  Write X3D output to this file instead of standard output.

*-x* _mask_, *--rt-debug*=_mask_::
  Set librt hexadecimal debug flags (see raytrace.h).

*-X* _mask_, *--nmg-debug*=_mask_::
  Set libnmg hexadecimal debug flags (see nmg.h).

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert selected regions to an X3D file
====
[source,console]
----
$ g-x3d -o havoc.x3d -u m -r 0.005 havoc.g havoc
----
Tessellates the region tree rooted at object *havoc* in *havoc.g* using a
relative tolerance of 0.005, scales the output to meters, and writes the
resulting X3D scene to *havoc.x3d* for viewing in a web browser or X3D viewer.
====

.Stream output through a pipeline
====
[source,console]
----
$ g-x3d -P 4 sample.g comp1 comp2 > parts.x3d
----
Converts two named objects using four processors and redirects the X3D scene to
*parts.x3d*. Because output defaults to standard output, *g-x3d* can be chained
with other tools in a pipeline.
====
