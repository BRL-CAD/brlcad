== NAME
fb-bw - save a framebuffer image in a black and white bw file

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*fb-bw* [*-i*] [*-F* _device_] [*-X* _pixels_] [*-Y* _pixels_] [*-s* _pixels_] [*-w* _pixels_]
      [*-n* _pixels_] [_output_]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*fb-bw* saves a region of a framebuffer display as a black and white *bw*(5) format file. The conversion is performed by computing an equal blending of the red, green, and blue channels. For more complex conversions, use *fb-pix*(1) and *pix-bw*(1).

By default, a first quadrant coordinate system is used (origin in the lower left of the screen), and the saved area starts from this origin.


[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-i*, *--inverse*::
  Use an upper-left origin and read scanlines from top to bottom.

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer device instead of the configured default.

*-X* _pixels_, *--x-offset*=_pixels_::
  Set the starting framebuffer X coordinate.

*-Y* _pixels_, *--y-offset*=_pixels_::
  Set the starting framebuffer Y coordinate.

*-s* _pixels_, *--size*=_pixels_::
  Set both output dimensions (default: 512).

*-w* _pixels_, *--width*=_pixels_::
  Set the output width (default: 512).

*-n* _pixels_, *--height*=_pixels_::
  Set the output height (default: 512).

// END GENERATED BU_ARG OPTIONS


[[examples]]
== EXAMPLES

.Grab the current framebuffer and threshold it into a silhouette
====
[source,console]
----
$ fb-bw -F /dev/X -s 1024 | bwmod -m 4 -c | bw-fb -s 1024
----
Reads the entire 1024x1024 framebuffer, converts it to a single grayscale
channel, brightens and clamps it with *bwmod*(1) to produce a high-contrast
silhouette, and displays the result back on the framebuffer with *bw-fb*(1).
====

.Save a specific region of the framebuffer to a file
====
[source,console]
----
$ fb-bw -X 256 -Y 256 -w 512 -n 512 region.bw
----
Captures a 512x512 region starting at screen offset (256, 256) from the
default framebuffer and writes the grayscale result to `region.bw`.
====
