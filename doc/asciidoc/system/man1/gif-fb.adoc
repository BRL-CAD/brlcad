== NAME

gif-fb - display a GIF image on a frame buffer

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*gif-fb* [*-c*] [*-o*] [*-v*] [*-z*] [*-F* _device_] [*-i* _number_] [_input_]
// END GENERATED BU_ARG SYNOPSIS


[[description]]
== DESCRIPTION

*gif-fb* decodes a CompuServe GIF (Graphics Interchange Format) image and
writes it to a frame buffer.  If no _gif_file_ is given, the GIF data is read
from standard input.  Multi-image GIF files are displayed sequentially unless a
single image is selected with *-i*.  The requested frame buffer is sized to the
GIF screen dimensions, and the image is written right-side-up at the bottom of
the available frame buffer.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-c*, *--force-color-resolution*::
  Use eight bits for each color channel.

*-o*, *--overlay*::
  Preserve the existing framebuffer background.

*-v*, *--verbose*::
  Report GIF screen, color-map, and image details.

*-z*, *--zoom*::
  Maximize the framebuffer view with square pixels.

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer device.

*-i* _number_, *--image*=_number_::
  Display only this 1-based GIF image.

// END GENERATED BU_ARG OPTIONS

Some non-standard GIF writers incorrectly declare their color resolution.
Use *--force-color-resolution* to treat each red, green, and blue channel as
eight bits.  By default, *gif-fb* clears the frame buffer to the GIF
background color before decoding; *--overlay* preserves the existing frame
buffer contents instead.  *--verbose* writes GIF screen, color-map, and image
details to standard error.  *--image* selects one image from a multi-image GIF
using a 1-based index; without it, images are displayed sequentially.

[[examples]]
== EXAMPLES

.Convert a GIF to a BRL-CAD pix file
====
[source,console]
----
$ gif-fb -F /dev/mem image.gif && fb-pix -F /dev/mem image.pix
----
Decode a GIF into an in-memory frame buffer and capture it with *fb-pix*(1),
producing a *pix*(5) file for use with the rest of the BRL-CAD image tools.
====

.View a single frame of an animated GIF, zoomed
====
[source,console]
----
$ gif-fb -z -i 3 animation.gif
----
Display only the third image of a multi-image GIF on the default frame buffer,
zoomed to fill the display while preserving square pixels.
====
