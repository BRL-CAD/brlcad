== NAME
plot3-fb - display a 3-D UNIX plot file on a framebuffer

// END GENERATED BU_ARG SYNOPSIS


[[description]]
== DESCRIPTION

*plot3-fb* rasterizes a BRL-CAD extended three-dimensional UNIX plot file and
displays the result on a framebuffer. Because 3-D UNIX plot is a superset of
the standard UNIX plot format, *plot3-fb* can also display ordinary 2-D plot
files (see *plot3*(5)).

If _file.plot3_ is omitted, the plot commands are read from standard input.
The framebuffer is selected with the *-F* option or, failing that, the
`FB_FILE` environment variable; otherwise the default device for your system is
used (see *brlcad*(1)).

By default the display is treated as 512x512 pixels. The *-S*/*-s*, *-W*/*-w*,
and *-N*/*-n* options set the screen size; the plotting space is scaled to fill
those dimensions, and no attempt is made to preserve the aspect ratio. Strokes
that fall outside the frame are limited (not clipped) to its edges; pre-process
with *plot3rot*(1) if true clipping or reorientation is desired.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-d*, *--debug*::
  Increase diagnostic output. May be repeated.

*-o*, *--overlay*::
  Preserve the existing framebuffer background.

*-i*, *--immediate*::
  Draw pixels immediately instead of buffering scanlines.

*-t* _pixels_, *--thickness*=_pixels_::
  Set the line thickness.

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer device.

*-s* _pixels_, *--size*=_pixels_::
  Set both framebuffer dimensions.

*-w* _pixels_, *--width*=_pixels_::
  Set the framebuffer width.

*-n* _pixels_, *--height*=_pixels_::
  Set the framebuffer height.

// END GENERATED BU_ARG OPTIONS

Repeating *--debug* increases the amount of command and framebuffer-coordinate
information written to standard error.  *--immediate* plots each rasterized
pixel as soon as it is computed instead of buffering scanlines into bands; it
can provide quicker feedback for small plots, but generally costs more CPU
time.  *--overlay* preserves the existing framebuffer image rather than
rasterizing over a cleared background.

*--thickness* widens each line perpendicular to its direction, up to the
line's length.  This can make single-pixel lines easier to resolve when
recording video.  *--framebuffer* overrides the `FB_FILE` environment
variable.  Dimension options are processed in command-line order, so a later
*--width* or *--height* can override one dimension set by *--size*, and a
later *--size* resets both dimensions.

[[examples]]
== EXAMPLES

.Render a wireframe of a database object straight to the framebuffer
====
[source,console]
----
$ fbserv -S 1024 0 /dev/X &
$ FB_FILE=:0 rt -o /dev/plot3 -s 1024 model.g component.r | plot3-fb -s 1024
----
Pipe the 3-D plot output of *rt*(1) for a region into *plot3-fb*, displaying the
wireframe on a 1024x1024 framebuffer started with *fbserv*(1) without writing an
intermediate file.
====

.Overlay thick annotation lines on an existing image
====
[source,console]
----
$ plot3-fb -o -t 3 -F /dev/X labels.plot3
----
Draw the strokes from labels.plot3 three pixels thick on top of whatever image
is already in the X framebuffer, leaving the background untouched.
====
