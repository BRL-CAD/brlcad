== NAME
terrain - generate a pseudo-terrain height field from procedural noise

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*terrain* [*-w* _postings_] [*-n* _postings_] [*-s* _postings_] [*-L* _factor_] [*-H* _value_]
        [*-O* _count_] [*-S* _factor_] [*-V* _x,y,z_] [*-D* _x,y,z_] [*-o* _value_] [*-f* _name_]
        [*-c*] [*-v*]
// END GENERATED BU_ARG SYNOPSIS


[[description]]
== DESCRIPTION

The *terrain* program produces a pseudo-terrain height field from
procedural noise, suitable for use with a BRL-CAD *dsp* (displacement
map) primitive. A noise value is computed for each point of an
_x_postings_ by _y_postings_ lattice and written to the standard output
as unsigned 16-bit integers in network (big-endian) byte order. The
default grid is 512 by 512 postings.

The character of the terrain is controlled by selecting a noise function
with *--function* and by tuning the fractal noise parameters. The standard
output must be redirected to a file; *terrain* refuses to write binary
data to a terminal. The resulting file is in the same binary format
produced by *asc2dsp*(1) and can be referenced directly by a *dsp* solid
in MGED.

Vector values may be written as one value with slash, comma, or semicolon
separators, as one quoted space-separated value, or as three separate
arguments. Options are applied from left to right. Consequently, a later
*--width* or *--height* may override one dimension set by *--size*, and a
later *--scale* or *--vector-scale* replaces the scale established by the
earlier option.


[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-w* _postings_, *--width*=_postings_::
  Set X postings (default: 512).

*-n* _postings_, *--height*=_postings_::
  Set Y postings (default: 512).

*-s* _postings_, *--size*=_postings_::
  Set equal X and Y postings.

*-L* _factor_, *--lacunarity*=_factor_::
  Set positive scale between successive noise octaves (default: 2.1753974).

*-H* _value_, *--fractal-increment*=_value_::
  Set positive fractal increment controlling detail across octaves (default: 1).

*-O* _count_, *--octaves*=_count_::
  Set positive number of noise octaves (default: 7).

*-S* _factor_, *--scale*=_factor_::
  Set all XYZ noise scales to a positive factor.

*-V* _x,y,z_, *--vector-scale*=_x,y,z_::
  Set independent finite XYZ noise scales (default: 0.0125,0.0125,0.0125).

*-D* _x,y,z_, *--delta*=_x,y,z_::
  Set finite XYZ noise-space translation (default: 1000,1000,1000).

*-o* _value_, *--offset*=_value_::
  Set multifractal and ridged offset (default: 1).

*-f* _name_, *--function*=_name_::
  Select the noise function (default: fbm). Accepted values: *fbm*, *turbulence*, *inverted-turbulence*, *multifractal*, *ridged-multifractal*, *lunar*, *lee*.

*-c*, *--host-order*::
  Write host byte order instead of portable network byte order.

*-v*, *--verbose*::
  Print noise-function and clamping diagnostics.

// END GENERATED BU_ARG OPTIONS


[[noise_functions]]
== NOISE FUNCTIONS

The *--function* option accepts the following canonical names. The
one-letter names in parentheses are compatibility aliases.

*fbm* (*f*)::
  Fractional Brownian motion. This is the default.

*turbulence* (*t*)::
  Turbulence noise.

*inverted-turbulence* (*T*)::
  One minus turbulence noise.

*multifractal* (*m*)::
  Multifractal noise using the value selected by *--offset*.

*ridged-multifractal* (*r*)::
  Ridged multifractal noise using the value selected by *--offset*.

*lunar* (*L*)::
  A lunar-like surface.

*lee* (*l*)::
  Terrain with detail concentrated on peaks and in valleys.


[[examples]]
== EXAMPLES

.Generate a terrain and build a dsp solid
====
[source,console]
----
$ terrain -w 256 -n 256 --function ridged-multifractal -O 8 -S 1.5 > hills.dsp
$ mged terrain.g <<'EOF'
in mountains.dsp dsp f hills.dsp 256 256 0 ad 1 100
EOF
----
A 256x256 ridged multi-fractal height field is written to hills.dsp,
then imported as a dsp primitive 256 cells wide and tall, smoothed,
with a cell width of 1 and a height multiplier of 100, yielding a
ridgeline of mountains in the database terrain.g.
====

.Create a tileable, square fBm patch
====
[source,console]
----
$ terrain -s 512 --function fbm -O 5 -L 2.0 -D 0,0,0 > patch.dsp
----
A 512x512 fractional Brownian motion field generated with five octaves
and a lacunarity of 2.0, sampled at the origin of noise space for a
repeatable result.
====
