== NAME
png-fb - display a PNG image file on a framebuffer

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*png-fb* [*-1*] [*-m* _scanlines_] [*-g* _gamma_] [*-H*] [*-i*] [*-c*] [*-v*] [*-z*] [*-F* _device_]
       [*-x* _pixels_] [*-y* _scanlines_] [*-X* _pixels_] [*-Y* _scanlines_] [*-S* _pixels_]
       [*-W* _pixels_] [*-N* _scanlines_] [_input_]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*png-fb* reads a Portable Network Graphics (*PNG*) format image from the named
file, or from standard input if no file is given, and displays it on the
currently selected framebuffer. The environment variable *FB_FILE* selects the
default framebuffer (see *brlcad*(1)); the *-F* option overrides it.

If no screen size is requested, the framebuffer is opened to match the size of
the input image. Grayscale and palette-based images are expanded to RGB, and
16-bit samples are reduced to 8 bits. The reverse conversion, writing a
framebuffer image to a PNG file, is performed by *fb-png*(1).

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-1*, *--one-line*::
  Force one scanline per framebuffer write.

*-m* _scanlines_, *--multiple-lines*=_scanlines_::
  Write blocks containing this many scanlines.

*-g* _gamma_, *--screen-gamma*=_gamma_::
  Set additional display gamma correction.

*-H*, *--header-only*::
  Print image dimensions without displaying the image.

*-i*, *--invert*::
  Display scanlines from top to bottom.

*-c*, *--clear*::
  Clear the framebuffer before writing.

*-v*, *--verbose*::
  Report PNG metadata while reading.

*-z*, *--zoom*::
  Zoom and center the displayed image.

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer instead of the FB_FILE environment default.

*-x* _pixels_, *--input-x-offset*=_pixels_::
  Skip pixels from the left of each input scanline.

*-y* _scanlines_, *--input-y-offset*=_scanlines_::
  Skip scanlines from the bottom of the input.

*-X* _pixels_, *--screen-x-offset*=_pixels_::
  Offset the image horizontally on the framebuffer.

*-Y* _scanlines_, *--screen-y-offset*=_scanlines_::
  Offset the image vertically on the framebuffer.

*-S* _pixels_, *--framebuffer-size*=_pixels_::
  Set both framebuffer dimensions.

*-W* _pixels_, *--framebuffer-width*=_pixels_::
  Set the framebuffer width.

*-N* _scanlines_, *--framebuffer-height*=_scanlines_::
  Set the framebuffer height.

// END GENERATED BU_ARG OPTIONS

*--header-only* writes `WIDTH=_width_ HEIGHT=_height_` to standard output in a
form suitable for shell scripts.  *--verbose* reports the color type, bit depth,
image size, gamma, interlace status, embedded text, and modification time when
present.  Additional screen gamma defaults to 1.0 (no correction), must be
positive, and lightens the displayed image as it increases.

*--one-line* overrides *--multiple-lines* regardless of option order.  Block
writes are used only for non-inverted, non-zoomed, unclipped transfers with
nonnegative framebuffer offsets and can be significantly faster on some
framebuffers.

Input offsets are nonnegative and measured from the lower-left corner of the
image.  Framebuffer offsets use the same origin but may be negative.  A zero
framebuffer width or height tracks the corresponding image dimension.  Zooming
uses equal integer factors in both directions to preserve the image aspect
ratio.

[[examples]]
== EXAMPLES

.Render a model and display the result
====
[source,console]
----
$ rt -o render.png -w 1024 -n 1024 havoc.g havoc
$ png-fb -c render.png
----
Ray-traces a geometry database to a 1024x1024 PNG file with *rt*(1), then
clears the framebuffer and displays the rendered image.
====

.Probe an image size from a script
====
[source,console]
----
$ eval $(png-fb -H earth.png)
$ echo "image is ${WIDTH} by ${HEIGHT}"
----
Uses *-H* to read back the dimensions of a PNG without displaying it, capturing
them as shell variables for further processing.
====
