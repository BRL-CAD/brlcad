== NAME
fbfade - fade a frame buffer image in or out

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*fbfade* [*-H*] [*-f* _device_] [*-F* _device_] [*-s* _pixels_] [*-w* _pixels_] [*-n* _pixels_]
       [*-S* _pixels_] [*-W* _pixels_] [*-N* _pixels_] [_output_]
// END GENERATED BU_ARG SYNOPSIS


[[description]]
== DESCRIPTION

*fbfade* paints a frame buffer one pixel at a time in a random order,
producing a dissolve effect. If an input image is given with *-f*, that
image is faded in; otherwise the output is painted black, fading out
whatever is currently displayed.

The output frame buffer is selected by *-F* (or as a trailing argument),
falling back to the *FB_FILE* environment variable or the default frame
buffer. The effective area is clamped to the smaller of the requested
size, the actual frame buffer size, and the input image size.

The dissolve uses a shuffled-index algorithm, so the effect is best on a
frame buffer with fast single-pixel writes.

== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-H*, *--high-resolution*::
  Use 1024 instead of 512 for unspecified input dimensions.

*-f* _device_, *--input-framebuffer*=_device_::
  Read the image to fade in from this framebuffer.

*-F* _device_, *--output-framebuffer*=_device_::
  Write the fade effect to this framebuffer.

*-s* _pixels_, *--input-size*=_pixels_::
  Set both input dimensions.

*-w* _pixels_, *--input-width*=_pixels_::
  Set the input width.

*-n* _pixels_, *--input-height*=_pixels_::
  Set the input height.

*-S* _pixels_, *--output-size*=_pixels_::
  Set both output dimensions.

*-W* _pixels_, *--output-width*=_pixels_::
  Set the output width.

*-N* _pixels_, *--output-height*=_pixels_::
  Set the output height.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Slide show with fade transitions
====
[source,console]
----
$ fbclear
$ for i in *.pix; do
    pix-fb "$i"
    fbfade -f /dev/mem
    sleep 5
    fbfade
done
----
Display each PIX image in the current directory with *pix-fb*(1), dissolve
it into view from the in-memory frame buffer, pause, then fade it back to
black before the next image.
====
