== NAME
patch-g - convert a preprocessed FASTGEN target description into a BRL-CAD database

== DESCRIPTION

*patch-g* converts FASTGEN target geometry into a BRL-CAD *.g* database.
FASTGEN is a modeling system used to create military target descriptions,
whose primitives (triangles in volume and plate mode, wedges, spheres,
boxes, cylinders, and rods) are reproduced by *patch-g* as NMG solids,
BoTs (polysolids), or ARB6 solids.

The FASTGEN file must first be passed through the *rpatch*(1) preprocessor,
which produces the intermediate ".rp" file that *patch-g* consumes. The
preprocessed input is read from standard input unless the *-f* option names
a file, and the resulting geometry is written to the *model.g* database named
as the sole positional argument.

By default solids are written as NMG primitives; *-p* selects BoT (polysolid)
output, and *-6* converts plate-mode triangles to ARB6 solids. Components are
grouped into regions with a fixed number of unions each (see *-T* and *-A* for
the tolerances controlling vertex fusing and face merging). Diagnostic
messages are emitted when geometry cannot be converted; the *-d* option raises
the verbosity, with higher levels producing more output.

== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-f* _fastgen.rp_, *--input*=_fastgen.rp_::
  Read rpatch-preprocessed FASTGEN data from this file instead of standard input.

*-n*, *--volume-as-plate*::
  Process volume-mode components as plate mode.

*-u* _count_, *--unions-per-region*=_count_::
  Set the positive number of union operations per region (default 5).

*-c* _x/y/z_, *--center*=_x/y/z_::
  Set the object center in inches for plate-mode normal calculations.

*-t* _text_, *--title*=_text_::
  Set the output database title (default: patch-g conversion).

*-o* _name_, *--top-level*=_name_::
  Set the whitespace-free top-level object name (default: all).

*-p*, *--polysolids*::
  Write volume- and plate-mode components as BoT polysolids instead of NMG solids.

*-6*, *--arb6*::
  Write plate-mode triangles as ARB6 solids, overriding --polysolids.

*-i* _groups.txt_, *--label-file*=_groups.txt_::
  Read component group labels from this file.

*-m* _materials.txt_, *--material-file*=_materials.txt_::
  Read component material properties from this file.

*-j* _jtype.txt_, *--jtype-file*=_jtype.txt_::
  Read thickness overrides in inches for components with no or zero thickness.

*-r*, *--reverse-normals*::
  Reverse plate-mode triangle surface normals. May be repeated.

*-d* _level_, *--debug*=_level_::
  Set a nonnegative diagnostic level; levels above 3 also write intermediate NMG solids.

*-x* _mask_, *--rt-debug*=_mask_::
  Set librt hexadecimal debug flags.

*-X* _mask_, *--nmg-debug*=_mask_::
  Set libnmg hexadecimal debug flags.

*-T* _inches_, *--distance-tolerance*=_inches_::
  Set nonnegative vertex-coincidence distance in inches.

*-A* _cosine_, *--perpendicular-tolerance*=_cosine_::
  Set the perpendicularity cosine tolerance from 0 through 1.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert a FASTGEN target to a polysolid BRL-CAD database
====
[source,console]
----
$ rpatch < tank.fastgen > tank.rp
$ patch-g -p -f tank.rp -t "M1 Tank" -o tank tank.g
----
First *rpatch*(1) preprocesses the raw FASTGEN file into the intermediate
*tank.rp*. *patch-g* then converts it, writing BoT (polysolid) geometry under
a top-level group named *tank*, with a database title of "M1 Tank", into the
new *tank.g* database that can be opened in *mged*(1).
====
