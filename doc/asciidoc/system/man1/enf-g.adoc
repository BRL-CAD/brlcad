== NAME
enf-g - convert an Elysium Neutral File (ENF) to a BRL-CAD database

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*enf-g* [_OPTION_]... _input_ _output_
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*enf-g* converts a tessellated _input_facets_file_ in the Elysium
Neutral File (ENF) format into a BRL-CAD _output.g_ database. The input
is expected to be the ASCII facet output produced by the Elysium
_enf2mxp_ tessellator. Each ENF part is written as a BOT primitive
wrapped in a region, and the ENF assembly hierarchy is reproduced using
combinations. When a part name mapping file is supplied, the original
ENF part number is also recorded as a *Part_No* attribute on the
resulting region or combination.

Region ident numbers begin at 1000 by default and increase for each
region. The default vertex merge distance is BRL-CAD's standard
distance tolerance; a requested tolerance must be greater than zero.
Generated object names may optionally be limited to five or more
characters.

A part-name mapping file contains a part number and legal BRL-CAD
object name on each line, separated by whitespace. Matching objects
are renamed, while unmatched objects retain their ENF part number and
produce a warning.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-v*, *--verbose*::
  Report objects as they are written.

*-i* _ident_, *--starting-ident*=_ident_::
  Set the first region ident (default 1000).

*-t* _millimeters_, *--tolerance*=_millimeters_::
  Set the positive vertex merge distance.

*-n* _file_, *--part-name-file*=_file_::
  Read part-number-to-name mappings from a file.

*-l* _characters_, *--name-length*=_characters_::
  Limit generated object name length.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert an ENF facet file with a custom ident range and name mapping
====
[source,console]
----
$ enf-g -v -i 2000 -l 32 -n parts.map widget.enf widget.g
----
Converts _widget.enf_ into _widget.g_, starting region idents at 2000,
limiting object names to 32 characters, and renaming parts via the
_parts.map_ lookup table. The resulting database can then be inspected
with *mged*(1) or rendered with *rt*(1).
====
