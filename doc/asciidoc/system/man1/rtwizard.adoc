== NAME
rtwizard - composite BRL-CAD images from color, ghost, and edge-line renderings

== SYNOPSIS

[source]
----
rtwizard [options] [-i] _geometry.g_ [-o] _output.{pix|png}_ [object ...]
----


[[description]]
== DESCRIPTION

*rtwizard* orchestrates several BRL-CAD utilities to produce composite
images of geometry in prescribed styles.  Full-color ray tracings are
produced by *rt*(1), "hidden-line" edge drawings by *rtedge*(1), and
semi-transparent greyscale "ghost" renderings by *rt*(1) combined with
BRL-CAD image-manipulation tools.  These layers are composited into a
single image written to a *pix*(5) or PNG file, or displayed on a
framebuffer.

*rtwizard* can also produce APNG or MJPEG animations.  Simple presets move a
cutting plane, orbit the camera around a fixed model, or rotate a database
object on a turntable.  A declarative JSON render specification can describe
the complete render and, when needed, general camera, cutting-plane,
transform, color, material, and temperature tracks.  Every full-color,
ghost, and edge pass uses the same state for each frame.

*rtwizard* has two modes.  With no arguments (or with *--gui*) it launches
a Qt workspace with a live libqtcad model view, hierarchy-based render-role
assignment, still-image controls, animation presets, camera-keyframe capture,
preview, render progress, cancellation, and a diagnostic log.  Render
specifications can be opened and saved directly; advanced tracks the workspace
does not edit are preserved.  Given sufficient options on the command line it
runs non-interactively, which is useful for scripting and bulk rendering.  If
a command line invocation lacks enough information to produce the requested
image, *rtwizard* falls back to the GUI unless *--no-gui* is given.

The GUI and command-line modes use the same C++17 rendering engine.  Renderer
processes are launched and managed with libbu, view state is resolved with
libged, images and animations are handled with libicv, and the application
does not evaluate Tcl startup or preference files.  A small, recognized subset
of legacy `.rtwizardrc` window settings is imported once as data.

The kind of image produced is governed by the *--type* option, or inferred
from which object lists are supplied.  The six picture types are:

.RtWizard Image Types
[cols="3*"]
|===
|Type |Name |Description

|A |Simple Full-Color Image |Standard *rt* image.
|B |Simple Line Drawing |Standard *rtedge* image.
|C |Highlighted Image |Full color *rt* image enhanced with *rtedge* lines.
|D |Mixed Full Color and Edges |Like C, but objects are selectively edge-enhanced.
|E |Ghost Image with Inserts |Full color elements over faded greyscale context.
|F |Ghost Image with Inserts and Edges |A Type E image further enhanced with *rtedge* lines.
|===

For compatibility with *rt*(1), the first unflagged argument naming an
existing .g file is taken as the input geometry, and the first unflagged
argument with a supported image extension (.pix, .png, .ppm, .bw, .dpix) is
taken as the output file.  Any remaining unflagged arguments are treated as
color objects.  Because this can be ambiguous, the *-i* and *-o* flags are
preferred.

[[options]]
== OPTIONS

*-h*, *--help*::
  Print the options summary and exit.

*--help-dev*::
  Print the developer/programmatic options and exit.

*-i* _filename_, *--input-file* _filename_::
  Input .g geometry database.  Overrides any unflagged .g argument.

*-o* _filename_, *--output-file* _filename_::
  Output image file.  A .png extension produces a PNG image; otherwise
  a BRL-CAD *pix*(5) image is written.  Other supported extensions are
  .ppm, .bw, and .dpix.  In animation mode, .png and .apng
  produce APNG while .avi and .mjpg produce MJPEG.

*--render-spec* _file.json_::
  Load a complete version 1 `brlcad.rtwizard.render` JSON specification.
  It may supply the database, object roles, image/output, view, style,
  runtime, and animation.  Ordinary command-line options override scalar
  values from the file; an explicit command-line object-role list replaces
  that JSON list.  Recipe filenames are resolved relative to the recipe.
  See `RtWizard Render Specification, Version 1` in the BRL-CAD
  specifications documentation.

*-s* _#_, *--size* _#_::
  Width and height of a square output image, in pixels (default 512).
  Overridden per-axis by *-w* and *-n*.

*-w* _#_, *--width* _#_::
  Output image width in pixels (overrides the width from *-s*).

*-n* _#_, *--height* _#_::
  Output image height in pixels (overrides the height from *-s*).

*--cut-steps* _#_::
  Produce a cutting-plane animation containing exactly this many frames.
  The value must be at least 2.  The first frame is just before clipping
  begins and the last is just before the rendered bounds are fully clipped.
  This is the compatibility shorthand for `--animation cut` with an exact
  frame count.

*--cut-direction* _x/y/z_::
  Model-space direction in which the cutting plane advances.  The vector is
  normalized internally; reversing it reverses the animation.  If omitted,
  the plane advances from the eye into the resolved render view.

*--animation-fps* _#_::
  Animation playback rate in frames per second (default 10).

*--animation* _cut|orbit|turntable_::
  Select an easy animation preset.  Orbit moves the camera while the model
  stays fixed; turntable moves a specified model path while the camera stays
  fixed.

*--animation-file* _file.json_::
  Read general animation tracks from a version 1 RtWizard render
  specification.  Usually *--render-spec* is more convenient because it can
  also supply the other render settings.

*--animation-duration* _seconds_::
  Animation duration (preset default 5).  Overrides JSON timing when given.

*--animation-frames* _#_::
  Exact number of frames.  If omitted, it is derived from duration and fps.

*--animation-plays* _#_::
  APNG playback count.  Zero means indefinite playback.  MJPEG ignores this
  metadata.

*--animation-cyclic* _0|1_::
  Whether sampling excludes a terminal frame that duplicates the first.
  Complete 360-degree orbit and turntable presets default to cyclic.

*--frame-dir* _directory_::
  Preserve completed animation frames as numbered PNG files.  The directory
  may be used with or without a final *-o* animation.

*--resume*::
  Reuse readable, correctly sized frames already in *--frame-dir*.  Without
  this option, an existing numbered frame is an error.

*--orbit-angle* _degrees_::
  Camera sweep for the orbit preset (default 360).

*--orbit-axis* _x/y/z_::
  Model-space orbit axis (default 0/0/1).

*--orbit-center* _x/y/z_::
  Fixed look-at target.  Defaults to the combined rendered-object bounds
  center.

*--orbit-elevation* _degrees_::
  Camera elevation above the plane normal to the orbit axis.  If omitted,
  the initial eye's elevation is preserved.

*--orbit-radius* _distance_::
  Camera distance from the orbit center.  If omitted, the initial eye's
  distance is preserved.

*--turntable-object* _path_::
  Database object or full path rotated by the turntable preset.  Required
  for that preset.

*--turntable-angle* _degrees_::
  Model rotation sweep (default 360).

*--turntable-axis* _x/y/z_::
  Model-space turntable axis (default 0/0/1).

*--turntable-center* _x/y/z_::
  Rotation pivot.  Defaults to the turntable object's bounds center.

*--save-view-keyframe* _file.json_::
  Save the resolved view as a camera keyframe in a render specification and
  exit without rendering.  Creates the file when necessary.

*--time* _seconds_::
  Nonnegative keyframe time required by *--save-view-keyframe*.

*--replace-keyframe*::
  Replace a camera keyframe already present at *--time* rather than report
  an error.

*-t* _A|B|C|D|E|F_, *--type* _A|B|C|D|E|F_::
  Picture type to produce (see the table above).  If a type is requested
  but the supplied object lists are insufficient for it, *rtwizard* exits
  with an error.

*-c* _obj[,...]_, *--color-objects* _obj[,...]_::
  Comma-separated list of objects to render in full color.  Quote the list
  if names contain spaces (e.g. -c "obj1,obj 2").

*-l* _obj[,...]_, *--line-objects* _obj[,...]_::
  Comma-separated list of objects to render as edge lines.

*-g* _obj[,...]_, *--ghost-objects* _obj[,...]_::
  Comma-separated list of objects to render as ghosted (faded) context.

*-a* _angle_, *--azimuth* _angle_::
  Set the azimuth view angle, in degrees.

*-e* _angle_, *--elevation* _angle_::
  Set the elevation view angle, in degrees.

*--twist* _angle_::
  Set the twist view angle, in degrees.

*-z* _value_, *--zoom* _value_::
  Zoom factor as a multiplier on the default view size.  Values greater
  than one enlarge the object; values less than one shrink it.

*--center* _x/y/z_::
  Set the xyz coordinates of the view center.

*--eye_pt* _x/y/z_::
  Set the eye point.  Part of a complete low-level view specification
  (with *--viewsize* and *--orientation*); a complete low-level
  specification overrides the high-level view options.

*--viewsize* _value_::
  Set the view size directly (low-level view specification).

*--orientation* _x/y/z/w_::
  Set the view orientation quaternion (low-level view specification).

*-P* _angle_, *--perspective* _angle_::
  Set the perspective angle, in degrees.

*-C* _color_, *--background-color* _color_::
  Background color for full-color ray tracing, as R/G/B or hex (default
  white).

*--line-color* _color_::
  Color for edge lines, as R/G/B or hex.  The keyword "region" uses each
  region's own color for its lines.

*--non-line-color* _color_::
  Color used for the non-line areas of edge renderings.

*-G* _value_, *--ghost-intensity* _value_::
  Visibility of ghosted objects (default 6.0).

*-O* _#_, *--occlusion* _#_::
  Occlusion mode (1 to 3) for line rendering (default 1).  See *rtedge*(1).

*--ao-samples* _#_::
  Number of ambient-occlusion samples per ray.  Zero disables ambient
  occlusion (default 0).

*--ao-radius* _value_::
  Maximum ambient-occlusion radius.  Zero uses *rt*'s unbounded default.

*--gui*::
  Force the graphical interface even when the command line specifies enough
  information to produce an image.

*--no-gui*::
  Force command-line operation even when the supplied information is
  insufficient.  Overridden by *--gui* if both are given.

*-d* _device_, *--fbserv-device* _device_::
  Framebuffer device for *fbserv*(1) to use instead of the default
  memory-only interface (e.g. -d /dev/wgl).  See *fbhelp*(1) for available
  devices.  A framebuffer started by *rtwizard* is closed automatically
  after image generation.

*-p* _#_, *--fbserv-port* _#_::
  Framebuffer service port.  With the default automatic transport, *rtwizard*
  launches a managed server over local IPC and uses this number only if it
  must fall back to TCP.  A TCP server selected explicitly is left open after
  rendering when it was already running.

*--fbserv-transport* _auto|ipc|tcp_::
  Select communication with a managed *fbserv*(1).  `auto` (the default)
  prefers BRL-CAD local IPC and falls back to TCP only when local IPC is not
  available.  `ipc` requires local IPC.  `tcp` preserves explicit TCP reuse
  and startup behavior.  Authentication is enabled for servers started by
  *rtwizard* regardless of transport.

*--benchmark*::
  Benchmark mode: disable randomness for reproducible timing.

*--cpu-count* _#_::
  Number of CPUs to use.

*--pid-file* _filename_::
  File used for tracking process IDs.

*--log-file* _filename_::
  Write debugging output to this file.

*-v* _#_, *--verbose* _#_::
  Set the verbosity level.

[[examples]]
== EXAMPLES

.Highlighted color-plus-edge image at a custom view
====
[source,bash]
----
rtwizard -i m35.g -c component/power.train -g component -l component \
         -a -35 -e 15 -z 1.6 -o m35.png
----
Render the m35 sample model with its power train highlighted in full color
over a ghosted, edge-lined truck body, viewed from azimuth -35 and
elevation 15 and zoomed in 1.6x, saving the result as a PNG image.
====

.Bulk rendering on the command line
====
[source,bash]
----
for g in *.g; do
    rtwizard --no-gui -t A -i "$g" -c all -s 1024 -o "${g%.g}.png"
done
----
Non-interactively produce a 1024x1024 full-color image of the "all" object
in every .g file in the current directory, naming each output after its
database.  *--no-gui* ensures the script never blocks on the GUI.
====

.Live preview on a framebuffer
====
[source,bash]
----
rtwizard -d /dev/wgl -i m35.g -l component
----
Display a line drawing of the m35 truck in an OpenGL framebuffer window
rather than writing it to a file.
====

.Cutting-plane animation
====
[source,bash]
----
rtwizard --no-gui -i model.g -c all -o cutaway.apng \
         --cut-steps 30 --cut-direction 0/0/-1 --animation-fps 12
----
Creates a 30-frame APNG with the cutting plane advancing in the negative Z
direction.  Use a `.png` or `.apng` output for APNG and `.avi` or `.mjpg` for
MJPEG.  Picture types using edge lines and the ambient-occlusion options may
be combined with the animation options.
====

.Orbit overview with restartable frames
====
[source,bash]
----
rtwizard --no-gui -i vehicle.g -c all -o overview.apng \
         --animation orbit --orbit-axis 0/0/1 --orbit-elevation 20 \
         --animation-duration 8 --animation-fps 24 \
         --frame-dir overview-frames
----
Moves the camera through a full circle around the rendered bounds center,
looking at that center throughout.  The model does not move.  Add *--resume*
to a later identical invocation to reuse valid frames.
====

.Complete render recipe
====
[source,bash]
----
rtwizard --render-spec vehicle-overview.json
----
Loads the database, objects, dimensions, output, style, view, and optional
animation from one declarative file.  For a one-off higher resolution render,
append `--size 1440`; the command-line value overrides the recipe.
====
