== NAME
wavelet - perform a Haar wavelet decomposition or reconstruction

== SYNOPSIS

        [*-D* _level_]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

The *wavelet* command performs a Haar wavelet transform on a raw binary
dataset read from standard input, writing the transformed result to
standard output.  It can either *decompose* a signal into successively
coarser "average" terms plus "detail" coefficients, or *reconstruct* the
original signal from such a decomposition.  Decomposition and
reconstruction are inverse operations.

The transform operates on interleaved, fixed-width samples, so it works
directly on image formats such as *pix*(5) and *bw*(5) by treating each
pixel as one sample with the appropriate number of channels.  A
two-dimensional transform requires a square dataset.

Because the Haar transform sums and differences sample values, results
can overflow narrow integer types.  For lossless decomposition and
reconstruction, first convert the stream to a wider representation with
*cv*(1), then select that representation with the *-t* option.  The *-t*
option interprets the input representation; it does not convert it.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-1*, *--one-dimensional*::
  Transform each scanline horizontally and independently (default).

*-2*, *--two-dimensional*::
  Transform a square dataset horizontally and vertically.

*-d*, *--decompose*::
  Decompose samples into average and detail coefficients.

*-r*, *--reconstruct*::
  Reconstruct samples from average and detail coefficients.

*-t* _type_, *--data-type*=_type_::
  Set the sample and arithmetic C data type (default: c/char). Accepted values: *c*, *s*, *i*, *l*, *f*, *d*.

*-#* _count_, *--channels*=_count_::
  Set interleaved values per sample (default: 3, as in RGB).

*-w* _samples_, *--width*=_samples_::
  Set samples per scanline (default: 512).

*-n* _scanlines_, *--height*=_scanlines_::
  Set scanline count (default: 512).

*-s* _samples_, *--size*=_samples_::
  Set equal square width and height.

*-W* _samples_, *--output-size*=_samples_::
  Stop decomposition at this power-of-two average width.

*-S* _samples_, *--square-output-size*=_samples_::
  Stop a two-dimensional transform at this power-of-two average size.

*-R* _samples_, *--average-size*=_samples_::
  Resume reconstruction from this power-of-two average image size.

*-D* _level_, *--debug*=_level_::
  Print data type, dimensions, channels, and transform limit diagnostics.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Display a horizontal decomposition
====
[source,console]
----
$ wavelet -d -# 3 -s 512 < img.pix | pix-fb
----
Decomposes each scanline of a 512x512 color *pix*(5) image and displays
the result on a framebuffer with *pix-fb*(1).  Each scanline shows a
shrinking "average" toward the left with detail coefficients to the right.
====

.Two-dimensional decomposition with a stopping size
====
[source,console]
----
$ wavelet -d -2 -# 3 -s 1024 -S 64 < img.pix > img.wlt
----
Performs a 2D decomposition of a 1024x1024 color image, stopping once the
average has been reduced to 64x64.  The output image holds a 64x64 version
of the original in the lower-left corner with detail terms filling the
remainder, ready to be inverted with *wavelet -r -2 -s 1024 -R 64*.
====
