== NAME

g-stl - convert BRL-CAD geometry to the STL file format

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*g-stl* [*-b*] [*-v*] [*-i*] [*-8*] [*-a* _distance_] [*-r* _fraction_] [*-n* _degrees_]
      [*-D* _distance_] [*-x* _mask_] [*-X* _mask_] [*-o* _output.stl_ | *-m* _directory_]
      _database.g_ _object_ ...
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

*g-stl* converts the specified _object_(s) from a BRL-CAD _database.g_ file into
the stereolithography (STL) file format by tessellating the geometry into
triangle facets via the NMG boolean evaluator. STL is widely used for 3D
printing and rapid prototyping.

By default an ASCII STL stream is written to standard output. With *-o* a single
STL file (ASCII or, with *-b*, binary) is produced; with *-m* each region is
written to a separate file in the named directory, with the region's path name
mangled into the file name ("/" becomes "@" and spaces or periods become "_").
Binary output cannot be sent to standard output. Output units default to
millimeters; see *-i*. Related converters include *g-obj*(1), *g-ply*(1), and
*stl-g*(1) for the reverse direction.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-b*, *--binary*::
  Write binary instead of ASCII STL; requires --output or --output-directory.

*-v*, *--verbose*::
  Report objects, tolerances, and conversion statistics.

*-i*, *--inches*::
  Write coordinates in inches instead of millimeters (the default).

*-8*, *--marching-cubes*::
  Tessellate with marching cubes instead of NMG boolean evaluation.

*-a* _distance_, *--absolute-tolerance*=_distance_::
  Set nonnegative maximum chord deviation in millimeters and clear relative tolerance.

*-r* _fraction_, *--relative-tolerance*=_fraction_::
  Set nonnegative tolerance as a fraction of the bounding box (default 0.01).

*-n* _degrees_, *--normal-tolerance*=_degrees_::
  Set nonnegative surface-normal tolerance in degrees and clear relative tolerance.

*-D* _distance_, *--distance-tolerance*=_distance_::
  Set nonnegative vertex-coincidence distance in millimeters (default 0.0005).

*-x* _mask_, *--rt-debug*=_mask_::
  Set librt hexadecimal debug flags.

*-X* _mask_, *--nmg-debug*=_mask_::
  Set libnmg hexadecimal debug flags.

*-o* _output.stl_, *--output*=_output.stl_::
  Write all geometry to this STL file (mutually exclusive with --output-directory).

*-m* _directory_, *--output-directory*=_directory_::
  Write each region to a separate STL file here (mutually exclusive with --output).

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Convert a component to a binary STL file for 3D printing
====
[source,console]
----
$ g-stl -b -i -a 0.1 -o bracket.stl model.g bracket
----
Tessellates the _bracket_ region from _model.g_ with a 0.1 mm absolute
tolerance, writing a compact binary STL in inch units suitable for slicing and
printing.
====

.Export every region of an assembly to separate files
====
[source,console]
----
$ mkdir parts
$ g-stl -m parts model.g assembly
----
Walks the _assembly_ tree and writes one ASCII STL file per region into the
_parts_ directory, each named after the region's full path. This is convenient
when downstream tools expect a single solid per file.
====
