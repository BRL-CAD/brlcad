== NAME
fbcbars - display standard color bars on a framebuffer

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*fbcbars* [*-e* | *-f* | *-s*] [*-F* _device_] [*-S* _pixels_] [*-W* _pixels_] [*-N* _scanlines_]
// END GENERATED BU_ARG SYNOPSIS


[[description]]
== DESCRIPTION

*fbcbars* displays a standard color bar scale on the currently selected framebuffer. By default, or when the *-s* option is provided, SMPTE color bars are displayed. Other supported patterns include FCC/EBU and EIA color bars. If no framebuffer is explicitly specified, the environment variable *FB_FILE* is used (see *brlcad*(1)). Ordinarily, the requested framebuffer size is the device default.

[[patterns]]
== PATTERNS

The EIA pattern places -I, 100% white, Q, and black across the bottom
quarter of the screen. The upper three quarters contain grey, yellow,
cyan, green, magenta, red, and blue at 75% intensity.

The FCC/EBU pattern fills the screen with 100% white, 75% yellow,
75% cyan, 75% green, 75% magenta, 75% red, 75% blue, and black.

The default SMPTE pattern modifies the EIA pattern by replacing the
upper quarter of its bottom region with a reversed and shifted copy of
the upper pattern. This region supports monitor color-demodulator
alignment: through a dichroic blue filter, adjust the chroma phase
until the magenta and cyan bars have equal apparent intensity.


[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-e*, *--eia*::
  Display EIA bars with -I, white, Q, and black below seven 75% colors.

*-f*, *--fcc*::
  Display full-screen FCC/EBU bars from white through 75% colors to black.

*-s*, *--smpte*::
  Display SMPTE color-demodulator alignment bars (default).

*-F* _device_, *--framebuffer*=_device_::
  Select the framebuffer instead of the FB_FILE environment default.

*-S* _pixels_, *--size*=_pixels_::
  Set both framebuffer dimensions.

*-W* _pixels_, *--width*=_pixels_::
  Set the framebuffer width.

*-N* _scanlines_, *--height*=_scanlines_::
  Set the framebuffer height.

// END GENERATED BU_ARG OPTIONS


[[examples]]
== EXAMPLES

.Capture SMPTE bars to a pix file for later use
====
[source,console]
----
$ fbcbars -s -S 512 -F /tmp/bars.pix
----
Opens the in-memory pix(5) file framebuffer `/tmp/bars.pix` at 512x512 and
writes the default SMPTE color bars into it. The resulting file can be
inspected with *pix-fb*(1) or converted to PNG with *pix-png*(1), which is a
convenient way to generate a reference test pattern without a physical display.
====

.Display FCC/EBU bars at HD resolution on the default framebuffer
====
[source,console]
----
$ FB_FILE=/dev/X fbcbars -f -W 1920 -N 1080
----
Displays full-screen FCC/EBU color bars at 1920x1080 on the framebuffer named
by the *FB_FILE* environment variable, here an X11 display. This is useful for
checking the color reproduction and geometry of a newly configured display
device.
====
