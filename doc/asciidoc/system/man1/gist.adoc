== NAME

gist - generate a one-page visual and textual summary of a geometry database

[[description]]
== DESCRIPTION

The Geometric Information Summary Tool (*gist*) produces a high-level,
one-page report describing a BRL-CAD database (*.g*) file. The report
is rendered to a PNG image that combines orthographic and perspective
views of the geometry with computed properties such as bounding
dimensions, surface area, volume, and mass, alongside the database's
top-level structure and report metadata (preparer, owner,
classification, and notes).

*gist* drives *rt*(1) and *rtwizard*(1) to produce its renders; the
directory holding those executables is located automatically or set
with *-T*. Intermediate renders are cached in a *.working* directory so
that subsequent runs can be re-used with *-Z*. If neither an output
file (*-o*) nor a folder of inputs (*-F*) is given, the report is shown
in a pop-up window instead of being saved.

A single database is summarized by naming it on the command line (or
with *-i*). Passing *-F* with a directory processes every *.g* file in
that directory, writing one report per model into an export folder.

== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-i* _filename.g_, *--input*=_filename.g_::
  Read this BRL-CAD database; a bare model.g operand is equivalent.

*-o* _filename.png_, *--output*=_filename.png_::
  Write the PNG report to this file; otherwise display it in a popup outside folder mode.

*-F* _folder_, *--folder*=_folder_::
  Process every BRL-CAD database in this folder.

*-e* _dir_name_, *--output-folder*=_dir_name_::
  Write folder-mode reports to this directory (default GIST_REPORTS inside the input folder).

*-g*, *--gui*::
  Display the generated report in a popup window.

*-f*, *--force*::
  Overwrite an existing report or export directory.

*-Z*, *--reuse-images*::
  Reuse renders from an existing .working directory.

*-t* _component_, *--top-component*=_component_::
  Feature this primary database object in the report.

*-m* _image_, *--logo*=_image_::
  Include this custom logo image in the report.

*-p* _ppi_, *--ppi*=_ppi_::
  Set positive output resolution (default 300 PPI).

*-n* _name_, *--preparer*=_name_::
  Record the report preparer's name.

*-r* _name_, *--owner*=_name_::
  Record the model owner's name.

*-T* _directory_, *--executables*=_directory_::
  Use rt and rtwizard from this directory instead of locating them automatically.

*-c* _classification_, *--classification*=_classification_::
  Show this classification in the report banners.

*-N* _text_, *--notes*=_text_::
  Include these additional notes in the report.

*-L*, *--left-handed*::
  Use a left-handed coordinate system (default right-handed).

*-A*, *--y-up*::
  Use +Y as the up axis (default +Z).

*-d* _file|0_, *--density-file*=_file|0_::
  Use this material density file, or 0 to skip density and mass calculations.

*-l* _units_, *--length-units*=_units_::
  Report dimensions in these length units.

*-w* _units_, *--mass-units*=_units_::
  Report mass in these units.

*-a* _directory_, *--working-directory*=_directory_::
  Write cached rendering work to this directory (default derived .working directory).

*-P* _count_, *--cpu-count*=_count_::
  Number of CPUs to use; 0 selects all available and negative values subtract from the available count.

*-Q*, *--preview*::
  Generate a low-resolution preview and mark omitted verification values unavailable.

*-v*, *--verbose*::
  Print detailed progress status.

*-h*, *--help*::
  Print help and exit.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Summarize a single model
====
[source,console]
----
$ gist -i ktank.g -o ktank.png -t tank -n "J. Doe" -c UNCLASSIFIED
----
Renders a report for the *ktank.g* database, featuring the *tank*
component, naming the preparer and stamping the report banners as
UNCLASSIFIED, and saves it to *ktank.png*.
====

.Re-run quickly after tweaking metadata
====
[source,console]
----
$ gist -Z -i ktank.g -o ktank_v2.png -N "revised mass properties"
----
Reuses the cached renders left in the *.working* directory from a
previous run (*-Z*), so only the report layout is regenerated with the
added notes rather than re-rendering all of the views.
====

.Batch-process a directory of models
====
[source,console]
----
$ gist -F models/ -e reports -p 600 -w lbs -l in
----
Generates a 600 ppi report for every *.g* file in *models/*, writing
them into a *reports* export folder and presenting weights in pounds
and lengths in inches.
====
