== NAME
bot_smooth - deprecated compatibility command for *bot normals*

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*bot_smooth* [*-t* _degrees_] _new_bot_ _old_bot_
// END GENERATED BU_ARG SYNOPSIS

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print command help.

*-t* _degrees_::
  Maximum angle between faces to smooth.

// END GENERATED BU_ARG OPTIONS

== DESCRIPTION

*bot normals* computes per-corner surface normals by averaging adjacent face
normals within _angle_tolerance_ degrees.  The default is 180 degrees.  If the
output name is omitted, the input object is updated in place.

This operation is distinct from *bot smooth*, which changes vertex positions
using geometric smoothing.  The *bot_smooth* name is therefore deprecated as
of BRL-CAD 7.48 in favor of the unambiguous *bot normals* spelling.

== EXAMPLE

[source,console]
----
mged> bot normals -t 60 rough.bot shaded.bot
----
