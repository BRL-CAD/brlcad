== NAME
art - Executes the BRL-CAD _art_ program.

== SYNOPSIS

[source]
----
art [options] [--objects]
----


[[description]]
== DESCRIPTION

The _art_ command launches BRL-CAD's Appleseed-backed renderer.  It uses
librt for BRL-CAD Boolean geometry and Appleseed for light transport and OSL
shading.  Run `art` from the command line, or select "Art" in MGED's raytrace
control panel.

The current renderer supports perspective and orthographic views, region
instances, inherited region colors, solid BOT geometry, OSL materials and
networks, and PNG, EXR, and BRL-CAD image output formats including PIX.
It remains under development and does not implement every *rt* option or
translate every legacy optical shader.  Refer to the "Rendering BRL-CAD
Models with art" article for material authoring, tested capabilities, and
remaining qualification boundaries.

Use `-o` to write an image to the requested path.  For example:

[source,console]
----
art -a 35 -e 25 -w 640 -n 480 -P 4 -c "set samples=64" -o view.png model.g all.g
----

Explicit shader, parameter, and asset errors cause rendering to fail.
Keep relative texture filenames and compiled shaders with the database
when moving a project.  Bundled shader libraries and OSL headers are resolved
from the application's installation; unstaged development builds use the
configured Appleseed dependency installation.


[[examples]]
== EXAMPLES

The following commands are entered in MGED.  Supply the path to the database
if it is not in the current directory.

.Render a square image with a white background.
====
[source,console]
----
mged> art -C 255,255,255 -s 1024 -o moss.png share/db/moss.g all.g
----

Writes a 1024-pixel square PNG image to `moss.png`.
====

.Render a rectangular orthographic view.
====
[source,console]
----
mged> art -a 35 -e 25 -w 640 -n 480 -p 0 -o moss.pix share/db/moss.g all.g
----

Writes the selected view as BRL-CAD PIX data to `moss.pix`.
====
