== NAME
bot_merge - deprecated compatibility command for *bot merge*

== DESCRIPTION

*bot merge* combines the vertex and face arrays of one or more BoTs into a
new object.  Input vertices are not fused; use *bot vertex-fuse* afterward if
coincident vertices should be combined.  Inputs should have compatible modes
and orientation semantics.

The *bot_merge* command name is deprecated as of BRL-CAD 7.48 and is retained
during the formal deprecation period.

== EXAMPLE

[source,console]
----
mged> bot merge combined.bot left.bot right.bot
----
