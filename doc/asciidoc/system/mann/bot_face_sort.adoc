== NAME
bot_face_sort - deprecated compatibility command for *bot sort*

== SYNOPSIS

[source]
----
bot sort triangles_per_piece bot [bot ...]
----

Compatibility form: `bot_face_sort triangles_per_piece bot [bot ...]`.

== DESCRIPTION

*bot sort* reorders faces into adjacent groups of _triangles_per_piece_ to
improve ray-tracing piece locality.  The selected objects are modified in
place.

The *bot_face_sort* command name is deprecated as of BRL-CAD 7.48 and is
retained during the formal deprecation period.

== EXAMPLE

[source,console]
----
mged> bot sort 4 bot1 bot2
----
