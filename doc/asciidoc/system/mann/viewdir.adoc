== NAME
viewdir - Returns the direction vector using the current azimuth and elevation (AE).

== SYNOPSIS

[source]
----
viewdir [-i]
----


[[description]]
== DESCRIPTION

Returns the direction vector using the current azimuth and elevation as input. If the _-i_ option is used the commmand will return the inverse directional vector.


[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-i*::
  Apply an incremental change.

// END GENERATED BU_ARG OPTIONS

== EXAMPLES

The example shows the use of the *viewdir* command to get the direction vector.
