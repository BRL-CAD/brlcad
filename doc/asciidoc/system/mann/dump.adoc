== NAME
dump - Copies the entire database to the __keep_file__.

== SYNOPSIS

[source]
----
dump {keep_file}
----


[[description]]
== DESCRIPTION

Copies the entire DB5 model to a new destination. The copy may be
smaller because it omits unused file space.

For embedded history or an LMDB workspace, the copy includes the complete
retained history and selected revision. Session history stays in the open
editor unless you explicitly use `db history export <path> --with-history`.


[[examples]]
== EXAMPLES

The example shows the use of the *dump* command to copy the entire database to a designated file.

.Copy the database to a designated file.
====

[source,console]
----
mged> dump sample.g
----
Creates _sample.g_ file which is a copy of the current database.
