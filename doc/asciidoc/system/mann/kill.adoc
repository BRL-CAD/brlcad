== NAME
kill - Deletes specified _objects_ from the current database.

== SYNOPSIS

[source]
----
kill [-f] [-n] [-q] {objects}
----


[[description]]
== DESCRIPTION

Deletes the specified _objects_ from the current database. This command affects only the _objects_ actually listed on the command line. If a combination is killed, its members are not affected. If the _-f_ option is specified, then kill will not complain if some, or all, of the _objects_ specified do not actually exist in the database. The _-n_ option performs a dry-run style report of the supplied object list instead of deleting it. The _objects_ are deleted immediately. With database history enabled, *db undo* restores the deleted objects. Other commands that remove objects from the database are *killall* and *killtree*.

The *-q* option may be added to suppress database object lookup messages reporting failure, which will otherwise let the user know an invalid object was specified.


[[examples]]
== EXAMPLES

The example shows the use of the *kill* command to delete specified objects from the database.

.Delete objects from the database.
====

[source,console]
----
mged> kill group1 region2 shapeb
----
Deletes _group1, region2_, and _shapeb_ from the database.
