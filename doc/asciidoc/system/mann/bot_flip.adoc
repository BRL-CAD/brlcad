== NAME
bot flip - Reverse all facet normals within a BoT primitive.

[[description]]
== DESCRIPTION

Reverse all facet normals within a BOT primitive. When viewing a BOT with the MGED 'e -m1' or 'draw -m1' command, if all the exterior facets are black and all interior facets are shaded (red by default), then this command will flip the normals resulting in all exterior facets becoming shaded and all interior facets becoming black. It is recommended to run *bot vertex-fuse* and *bot face-fuse* before *bot flip*.

The command toggles the orientation of right and left-handed BOT primitives. The orientation of unoriented BOT primitives will not change.  The legacy *bot_flip* spelling is deprecated as of BRL-CAD 7.48.

[[examples]]
== EXAMPLES

.Flip a BoT whose outward-facing normals are reversed.
====
[source,console]
----
mged> bot flip imported_shell.bot
----

Reverses every facet normal in _imported_shell.bot_, which is a common follow-up after finding that the model's outside faces render as backfaces in shaded mode.
