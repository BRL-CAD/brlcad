== NAME
joint - manage kinematic joint and constraint data for articulated models

== SYNOPSIS

[source]
----
joint subcommand [args]
joint object joint_name operation [args]
joint graph evaluate root_link joint_name [joint_name ...]
joint solve point root_link target_link px py pz tx ty tz joint_name [joint_name ...]
joint legacy subcommand [args]
----


[[description]]
== DESCRIPTION

The *joint* command is the front door for articulated model operations.
The *object* namespace operates on persistent database-backed joint objects.
The *legacy* namespace explicitly selects the transient file-loaded joint and
constraint implementation.  Existing unnamespaced legacy forms remain aliases
for compatibility.

Database-backed joints define stable parent and child links, optional geometry
path bindings, rigid attachment frames, ordered degrees of freedom, and an
affine pose.  Object operations include `show`, `validate`, `matrix`, `apply`,
`position`, and `pose`; see *joint2*(nged) for their current behavior.

=== Subcommands

[cols="1,2,3"]
|===
|Subcommand |Arguments |Description

|`object`
|joint_name operation [args]
|Operate on a persistent database-backed joint object.

|`legacy`
|subcommand [args]
|Explicitly select the transient legacy implementation.

|`graph evaluate`
|root_link joint_name [joint_name ...]
|Evaluate and print root-to-link matrices for a persistent joint graph.

|`solve point`
|root_link target_link px py pz tx ty tz joint_name [joint_name ...]
|Position persistent joint DOFs so a link-local point reaches a world target.

|`?`
|[commands]
|List available subcommands.

|`accept`
|[joints]
|Accept (commit) a series of joint moves.

|`debug`
|[hex code]
|Show or set the debugging bit vector.

|`help`
|[commands]
|Print usage information for the specified subcommands.

|`holds`
|[names]
|List the currently loaded constraint holds.

|`list`
|[names]
|List the currently loaded joint objects.

|`load`
|file_name
|Load joint and constraint definitions from a file.

|`mesh`
|
|Build the kinematic grip mesh from loaded joints.

|`move`
|joint_name p1 [p2 ... p6]
|Manually adjust a joint by specifying one or more parameter values.

|`reject`
|[joint_names]
|Reject (undo) joint position changes.

|`save`
|file_name
|Save current joint and constraint definitions to a file.

|`legacy solve`
|constraint
|Run the quarantined legacy heuristic solver for loaded constraints.

|`unload`
|
|Unload all joints and constraints from memory.

|===

[[examples]]
== EXAMPLES

.Load a joint file
====
[source,console]
----
mged> joint load arm_joints.jnt
----

Loads joint definitions from `arm_joints.jnt`.
====

.Position a database-backed joint
====
[source,console]
----
mged> joint object elbow.j position 0 45
mged> joint object elbow.j apply
----

Sets the first degree of freedom and applies the resulting relationship matrix
to the bound child geometry instance.
====

.Solve a point target
====
[source,console]
----
mged> joint solve point base tool 0 0 0 100 25 50 shoulder.j elbow.j
mged> joint object shoulder.j apply
mged> joint object elbow.j apply
----

Uses bounded damped least squares to move the origin of `tool` to the target
point.  Coordinates use database local units.  Solved joint objects are stored
in the database; `apply` updates their bound geometry instances for drawing and
ray tracing.
====

.List joints
====
[source,console]
----
mged> joint list
----

Lists all currently loaded joints.
====

.Move a joint
====
[source,console]
----
mged> joint move elbow_joint 45
----

Sets the `elbow_joint` position parameter to 45.
====

.Accept the current joint positions
====
[source,console]
----
mged> joint accept
----

Commits all pending joint moves to the model.
====
