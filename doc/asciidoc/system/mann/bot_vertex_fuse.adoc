== NAME
bot_vertex_fuse - deprecated compatibility command for *bot vertex-fuse*

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS

*bot_vertex_fuse* _new_bot_ _old_bot_

== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print command help.

// END GENERATED BU_ARG OPTIONS

== DESCRIPTION

*bot vertex-fuse* merges vertices whose positions are equal within the
database tolerance and updates face references.  If _output_bot_ is omitted,
the result is written to _input_bot-out_vertex_fuse.bot_.

The *bot_vertex_fuse* name and output-first ordering are deprecated as of
BRL-CAD 7.48 and are retained during the formal deprecation period.

== EXAMPLE

[source,console]
----
mged> bot vertex-fuse bot1_original bot1_fused
----
