== NAME
bot_condense - deprecated compatibility command for *bot condense*

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS

== DESCRIPTION

*bot condense* removes vertices not referenced by any face.  If _output_bot_
is omitted, the result is written to _input_bot-out_condense.bot_.  The source
object is not modified.

The *bot_condense* name is deprecated as of BRL-CAD 7.48.  It remains
available during the formal deprecation period for existing scripts, but new
usage should use *bot condense* and its input-first argument order.

== EXAMPLE

[source,console]
----
mged> bot condense bot1_original bot1_condensed
----
