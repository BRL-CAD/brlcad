== NAME
bot_fuse - deprecated compatibility command for *bot fuse*

== SYNOPSIS

[source]
----
bot fuse [-s|-p] input_bot [output_bot]
----

Compatibility form: `bot_fuse [-s|-p] output_bot input_bot`.

== DESCRIPTION

*bot fuse* converts the input through NMG topology, fuses coincident vertices,
edges, and faces using the database tolerance, and writes a healed BoT.  If
_output_bot_ is omitted, the result is written to _input_bot-out_fuse.bot_.

`-s` displays open output edges and `-p` writes them to a plot file.  This
operation rebuilds topology and may not preserve BoT-specific normals, texture
coordinates, or plate metadata; use *bot vertex-fuse* and *bot face-fuse* when
only duplicate vertices or faces need removal.

The *bot_fuse* name and output-first ordering are deprecated as of BRL-CAD
7.48 and are retained during the formal deprecation period.

== EXAMPLE

[source,console]
----
mged> bot fuse damaged.bot healed.bot
----
