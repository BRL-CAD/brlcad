== NAME
bot dump - export Bag-of-Triangles (BOT) geometry to a mesh file format

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*bot_dump* [_OPTION_]... [_bot_ ...]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

The *bot dump* command exports one or more BOT (Bag-of-Triangles) primitives from the current database to an external mesh file. If no BOT names are specified, all BOT objects in the database are exported.  The legacy *bot_dump* spelling is deprecated as of BRL-CAD 7.48.

Output formats supported:

* *stl* — STL (Stereolithography), the default. Binary or ASCII.
* *dxf* — AutoCAD DXF format.
* *obj* — Wavefront OBJ format (with an accompanying `.mtl` material file).
* *sat* — ACIS SAT format.
* *glb* — glTF binary format.
* *gltf* — glTF JSON format.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print command help.

*-b*::
  Use binary output when the selected format supports it.

*-n*, *--normals*::
  Write normals when the selected format supports them.

*-m* _directory_, *--output-directory*=_directory_::
  Write one file per BoT into this directory.

*-o* _file_, *--output-file*=_file_::
  Write to this output file.

*-t* _format_::
  Select dxf, glb, gltf, obj, sat, or stl output. Accepted values: *dxf*, *glb*, *gltf*, *obj*, *sat*, *stl*.

*-u* _units_::
  Scale exported coordinates to these units.

*-F*, *--full-precision*::
  Write full floating-point precision (nonstandard for glTF).

*--displayed*::
  Write displayed geometry.

*--viewdata*::
  Write non-geometry view data.

*--materials*::
  Write material and color information.

*--no-materials*::
  Do not write material or color information.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.Export all BOTs to a single STL file
====
[source,console]
----
mged> bot dump -o scene.stl
----

Exports all BOT primitives in the database to `scene.stl` in ASCII STL format.
====

.Export a specific BOT as binary STL
====
[source,console]
----
mged> bot dump -b -o hull_mesh.stl hull.bot
----

Exports `hull.bot` to `hull_mesh.stl` in binary STL format.
====

.Export to OBJ format with named per-object files
====
[source,console]
----
mged> bot dump -t obj --output-directory ./export/
----

Exports each BOT in the database to its own `.obj` file in the `./export/` directory, including color/material data when available.
====

.Export in glTF binary format
====
[source,console]
----
mged> bot dump -t glb -o scene.glb
----

Exports all BOTs to `scene.glb` in standard binary glTF format.
====

.Export in DXF format with unit conversion
====
[source,console]
----
mged> bot dump -t dxf -u in -o scene.dxf
----

Exports all BOTs to `scene.dxf` in DXF format, with coordinates converted to inches.
====
