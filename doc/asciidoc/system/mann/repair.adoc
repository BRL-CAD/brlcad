== NAME
repair - Attempts to repair invalid data in the __name__ object.

== SYNOPSIS

[source]
----
repair [-o output_obj] {name}
----


[[description]]
== DESCRIPTION

Using the existing __name__ object definition, attempts to repair any flaws.
This operation is not guaranteed to succeed for all inputs, but can sometimes
correct "almost" valid shape parameters or otherwise improve them.  The
specfics of how it works are primitive type dependent.

[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print command help.

*-o* _name_, *--output-name*=_name_::
  Write the repaired object to a new object.

*--options-json*::
  Return the primitive-specific repair options as JSON.

*-t* _distance_, *--tol*=_distance_::
  Distance tolerance for primitives that support vertex snapping.

*-p* _percent_, *--max-hole-percent*=_percent_::
  Maximum hole area as a percentage of mesh area.

*-a* _area_, *--max-hole-area*=_area_::
  Maximum hole area in mm.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

The example shows the use of the *remove* command to repair __name__  and store the repaired output as __new_name__.

.Repair an object.
====
[source,console]
----
mged> repair -o repaired_shape shape
----

Fixes _shape_ and saves it as _repaired_shape_.
