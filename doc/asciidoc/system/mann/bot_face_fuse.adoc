== DESCRIPTION

*bot face-fuse* removes duplicate faces while preserving plate thickness and
face mode, surface normals, texture coordinates, and object attributes.  If
the output name is omitted, the result is written to
_input_bot-out_face_fuse.bot_.

The *bot_face_fuse* name and its output-first ordering are deprecated as of
BRL-CAD 7.48 and are retained only for the formal compatibility period.

== EXAMPLE

[source,console]
----
mged> bot face-fuse bot1_original bot1_fused
----
