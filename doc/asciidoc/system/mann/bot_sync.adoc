== NAME
bot sync - Synchronize connected facet orientations within a BoT.

== SYNOPSIS

[source]
----
bot sync {bot} [bot2 bot3]...
----


[[description]]
== DESCRIPTION

Synchronizes connected BOT facets so they share a consistent orientation.  It
is recommended to run *bot vertex-fuse* and *bot face-fuse* first.  If the
result is consistently inward-facing, use *bot flip*.  The legacy *bot_sync*
spelling is deprecated as of BRL-CAD 7.48.

[[examples]]
== EXAMPLES

.Normalize facet winding before checking overall orientation.
====
[source,console]
----
mged> bot sync imported_mesh.bot
----

Synchronizes neighboring facet normals in _imported_mesh.bot_ so they all point consistently, making it easier to see whether a later *bot_flip* is needed.
====
