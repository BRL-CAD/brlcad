== NAME
keep - Copies the _objects_ specified to the __keep_file__.

== SYNOPSIS

[source]
----
keep [-R] {keep_file} {objects}
----


[[description]]
== DESCRIPTION

Copies the _objects_ specified to the __keep_file__. If __keep_file__ does not
exist, it is created. If __keep_file__ does exist, the _objects_ are appended
to it. The __keep_file__ is a _BRL-CAD_ database file. The _objects_ in the
list must exist in the current database.

By default, *keep* recursively follows the members of named combinations.
Use *-R* to skip combination traversal. Exported primitives include their
referenced sketches and database-backed bitmap, displacement, or volume
samples. References to external files keep their stored paths.

The output is a geometry-only database. To export a complete model with
its retained revisions, use `db history export --with-history path.g`.
Use a new file or an existing writable plain database as the destination.


[[examples]]
== EXAMPLES

The example shows the use of the *keep* command to copy specified objects to a designated file.

.Copy specified objects to a designated file.
====

[source,console]
----
mged> keep sample.g sample1 sample2
----
Creates _sample.g_ file with objects _sample1_ and _sample2_ in it.
