== NAME
oscale - This command of matrix edit mode modifies the matrix to perform a uniform scale operation.

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*oscale* _object_ _scale_factor_ [_keypoint_ ...]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

This command of matrix edit mode modifies the matrix to perform a uniform scale operation. A __scale_factor__ of 2 doubles the size of the associated object, and a __scale_factor__ of 0.5 reduces it by half.


[[examples]]
== EXAMPLES

The example shows the use of the *oscale* command to increase the size of a currently edited object by a specified factor.

.Increase a currently edited object by a specified factor.
====
[source,console]
----
mged> oscale 3
----

Increases the size of the currently edited object by a factor of 3.

====
