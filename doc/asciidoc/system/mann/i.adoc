== NAME
i - Adds __obj_name__ to the end of the combination named __comb_name__. The _operation_ may be "+," "-," or "u."

== SYNOPSIS

// BEGIN GENERATED BU_ARG SYNOPSIS
[verse]
*i* _object_ _combination_ [(*u* | *-* | *+*)]
// END GENERATED BU_ARG SYNOPSIS

[[description]]
== DESCRIPTION

Adds __obj_name__ to the end of the combination named __comb_name__. The _operation_ may be "+," "-," or "u." If no _operation_ is specified, "u" is assumed. If __comb_name__ does not exist, it is created.


[[examples]]
== EXAMPLES

The example shows the use of the *i* command to add a specified region to a combination (group).

.Add an object to a combination (group).
====

[source,console]
----
mged> i region3 group5
----
Adds _region3_ to the combination _group5_.
