== NAME
bo - Creates or retrieves binary opaque objects.

== SYNOPSIS

[source]
----
bo -i u [h|n]type destination source
bo -o destination source
----


[[description]]
== DESCRIPTION

Used to create or export binary opaque objects. One of _-i_ or _-o_ must be
specified to input or output data respectively. The _-i_ option creates a
binary object, and the _-o_ option writes out a binary object's data. Currently,
only uniform binary objects (arrays of values) are supported on input.

With database history enabled, *bo -i* records the imported object in the current edit. To replace an existing binary object in one revision, run *kill* and *bo -i* for the same name in a *db history batch*.

On input, _destination_ is the name of the object to create and _source_ is the
path to a file to read. Input data defaults to host byte order. Prefix _type_
with `h` to specify host byte order explicitly or `n` to specify network byte
order. The base _type_ may be one of:


* f -> float
* d -> double
* c -> char (8 bit)
* s -> short (16 bit)
* i -> int (32 bit)
* l -> long (64 bit)
* C -> unsigned char (8 bit)
* S -> unsigned short (16 bit)
* I -> unsigned int (32 bit)
* L -> unsigned long (64 bit)



Note: this command was previously named "dbbinary".

On output, _destination_ is a new path for the binary object's host-order
data. Export is available from read-only and versioned databases and runs
as a standalone command outside a history batch.


[[examples]]
== EXAMPLES

The examples show the use of the *bo* command to both create (_-i_ option) and to retrieve a binary object (_-o_ option).

.Create an opaque uniform binary object of characters with a specified name containing the contents of a particular file.
====
[source,console]
----
mged> bo -i u c cmds /usr/brlcad/html/manuals/mged/mged_cmds.html
----

Creates an opaque uniform binary object of characters with the name _cmds_ that contains the contents of the file __/usr/brlcad/html/manuals/mged/mged_cmds.html__.

====

.Import data for a displacement map (DSP) object
====
[source,console]
----
mged> bo -i u nS dsp.data /path/to/file.dsp
----

This imports a standard network-order DSP file containing unsigned short
(16-bit) data. The data is saved in the `.g` database into an object named
_dsp.data_. When creating a DSP, this _dsp.data_ object can be specified as the
data source.

====

.Copy the contents of a particular binary object into a specified file.
====
[source,console]
----
mged> bo -o /home/jim/cmds.html cmds
----

Copies the contents of the binary object named _cmds_ into the file named
_/home/jim/cmds.html_. Multibyte values are written in host byte order.

====
