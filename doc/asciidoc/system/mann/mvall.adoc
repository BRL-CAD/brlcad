== NAME
mvall - Changes the name of __old_name__ to __new_name__ wherever it occurs in the database.

== SYNOPSIS

[source]
----
mvall [-n] [(-f mapping_file) | (old_name new_name)]
----


[[description]]
== DESCRIPTION

Changes the name of __old_name__ to __new_name__ and updates references in combinations and in DSP or VOL primitives that use the object as their sample grid. Use _-f_ to read name pairs from __mapping_file__. Use _-n_ to list the affected objects before editing, including on a read-only database. With database history enabled, *db undo* restores the object name and its references together.


[[examples]]
== EXAMPLES

.Change the name of an object everywhere it occurs in the database.
====
[source,console]
----
mged> mvall shapea shapeb
----

Changes the name of _shapea_ to _shapeb_ everywhere it occurs in the database.

====

.This example shows a simple mapping file.
====

[source,text]
----
# this line is a comment
old_name new_name
foo bar # another comment, replacing foo with bar
bad_name good_name
----

====
