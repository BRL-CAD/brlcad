== NAME
joint2 - compatibility alias for database-backed articulation joints

== SYNOPSIS

[source]
----
joint2 joint_name show
joint2 joint_name validate
joint2 joint_name matrix
joint2 joint_name apply
joint2 joint_name position index [value]
joint2 joint_name pose [translation|rotation|scale [values...]]
----

[[description]]
== DESCRIPTION

The *joint2* command is a deprecated compatibility alias for
`joint object`.  New scripts should use `joint object joint_name operation`.
A database-backed joint relates stable parent and child
link identifiers, may bind those links to geometry paths, and defines rigid
attachment frames, ordered mechanical degrees of freedom (DOFs), and an affine
pose.

The operations are:

* *show* prints the complete joint definition.
* *validate* checks the joint definition and resolves any geometry path bindings.
* *matrix* prints the child-to-parent relationship matrix.
* *apply* replaces the bound child combination-instance matrix with the
  evaluated relationship matrix.  The child path must directly descend from
  the parent path.  Repeated application is idempotent; transforms do not
  accumulate.
* *position index* reports a DOF position.  Supplying `value` updates it.
  Rotational values use degrees; translational values use database local units.
* *pose* reports translation, rotation, and scale.  A component name reports
  only that component.  Supplying values updates the component.  Translation
  uses database local units, rotation is a unit Hamilton quaternion in `x y z w`
  order, and scale is unitless.

The relationship matrix is evaluated as `parent_frame * mechanical_motion *
pose * inverse(child_frame)`.  Mechanical DOFs are evaluated in their stored
order.  The pose matrix uses translation, then quaternion rotation, then scale.

[[examples]]
== EXAMPLES

.Set and inspect a revolute position
====
[source,console]
----
mged> joint2 elbow.j position 0 45
mged> joint2 elbow.j apply
mged> joint2 elbow.j position 0
45
----
====

.Apply a non-uniform pose scale
====
[source,console]
----
mged> joint2 elbow.j pose scale 1 1 1.25
mged> joint2 elbow.j matrix
----
====
