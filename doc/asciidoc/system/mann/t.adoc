== NAME
t - Alternate command name for *ls*.

== SYNOPSIS

[source]
----
t [-A -o -a -c -r -s -p -l -q -H -S] [objects]
----


[[description]]
== DESCRIPTION

The *t* command shares its core implementation with *ls* and accepts the same
arguments and options.

See *ls* for the detailed option descriptions and examples.


[[options]]
== OPTIONS

// BEGIN GENERATED BU_ARG OPTIONS
*-h*, *--help*::
  Print help and exit.

*-a*, *--all*::
  Do not ignore hidden objects.

*-c*, *--combs*::
  List combinations.

*-r*, *--regions*::
  List regions.

*-p*, *--primitives*, *-s*::
  List primitives.

*-q*, *--quiet*::
  Suppress informational output messages during database lookup.

*-l*::
  Use long reporting format.

*-H*, *--human-readable*::
  When printing in long format, use human-readable object sizes.

*-S*, *--sort*::
  Sort by object size.

*-A*, *--attributes*::
  Treat operands as attribute name/value pairs.

*-o*, *--or*::
  In attribute mode, match any attribute pair.

// END GENERATED BU_ARG OPTIONS

[[examples]]
== EXAMPLES

.List all regions matching a name pattern.
====
[source,console]
----
mged> t -r wheel
----

Lists regions whose names begin with _wheel_.

====
