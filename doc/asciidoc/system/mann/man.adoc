== NAME
man - displays a manual page graphically or as formatted text.

== SYNOPSIS

[source]
----
man [manual_page [section]]
man [-g | --gui] [manual_page [section]]
man [--no-gui | --dump] [--width columns] [-L language] [-S section] [manual_page [section]]
man [-h | --help]
----


[[description]]
== DESCRIPTION

Launches the BRL-CAD manual page viewer for the specified command name.

By default, *man* starts the GUI viewer when possible. It can also force GUI or
non-GUI mode and can select a manual language or manual section before
launching `brlman`.  A trailing section argument is accepted for compatibility
with `man view 3`; the explicit *-S* option is preferred.


[[options]]
== OPTIONS

*-h*, *--help*::
Print help and exit.

*-g*, *--gui*::
Force use of the graphical manual page viewer.

*--no-gui*::
Return formatted manual text in the command result, including GUI consoles.

*--dump*::
Return formatted text, equivalent to *--no-gui*. No external pager is launched.

*--width* _columns_::
Set the positive wrapping width for text output (default: 80). Literal examples
retain their original line breaks and may exceed this width.

*-L*, *--language* _lang_::
Select the manual language to request from `brlman`.

*-S*, *--section* _section_::
Select manual section `1`, `3`, `5`, or `n` to request from `brlman`.


[[examples]]
== EXAMPLES

.Open the *view* manual page in the default viewer mode.
====
[source,console]
----
mged> man view
----

Launches the BRL-CAD manual page viewer on the `view` command page.

====

.Open a specific section in command-line mode.
====
[source,console]
----
mged> man --no-gui -S 1 rt
----

Displays the section `1` manual for `rt` as text in the command console.

====
